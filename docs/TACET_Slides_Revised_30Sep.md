## หน้า 3 — What is this Game?
> **Genre :** Roguelike + Rhythm
> **แนวคิดหลัก :** *"You do not play the notes. You lead the band that does."*
> ผู้เล่นเป็นวาทยากร ใช้เมาส์เป็นไม้บาตอง คุมวงดนตรีสู้กับ **TACET** ความเงียบที่กลืนโลก
> **วิธีเล่น :** อ่านโน้ต → ตวัดไม้ให้ถูกทิศ ถูกขนาด ตรงจังหวะ → ทั้งวงเล่นเพลง → ดันความเงียบถอยกลับ

- ตัด "Planing team" และ "จัดทีม" ออก (เกมตอนนี้ไม่มีการจัดทีมก่อนสู้แล้ว ทั้งวงเล่นทุกโน้ต)

## หน้า 8 — Game Loop
> 1. เมนูหลัก → 2. เลือกวาทยากร (5 คน สไตล์ต่างกัน + โหมด NORMAL / MAESTRO)
> 3. เปิดชั้นใหม่ : เลือกยุค + รับนักดนตรี
> 4. เลือกเส้นทาง : ดวล · ร้าน · พัก · เหตุการณ์
> 5. ดวล (Core Game Loop) → 6. รับรางวัล → วนจนเจอบอส
> ชนะบอส → ชั้นถัดไป (ชั้น 1 → 2 → 3) · ชนะชั้น 3 = จบเกม · แพ้ = เริ่มรันใหม่

## หน้า 9 — Core Game Loop
> **อ่านโน้ต** : ลูกศร = ทิศ · ตัวอักษร = ขนาด (p เล็ก · mf กลาง · f ใหญ่)
> **ตวัดไม้บาตอง** : ตามทิศ ตามขนาด ตรงจังหวะ
> **วงเล่นเพลง** : ทั้งวงเล่นโน้ตนั้นพร้อมกัน
> **ดันความเงียบ** : ชนะบีตดันเส้น · แพ้บีตเสียลม
> ดันเส้นจนสุด = ชนะ · ลมหมดก่อน = แพ้

- แก้ "จุนสุด" → จนสุด · "ขวาด" → ขนาด · "หมดทีมลมก่อนแพ้" → ลมหมดก่อน = แพ้
- ภาพ `docs/diagrams/core_game_loop.png` ใช้แทนได้

## หน้า 15 — Game Design
> **Genre :** Roguelike + Rhythm
> **Gameplay :** ดนตรีปะทะความเงียบ — TACET คือความมืดที่ค่อยๆ กลืนจอ ผู้เล่นต้องเล่นจังหวะให้ถูกเพื่อดันมันกลับ
>
> **ระบบในเกม**
> 1. **Rhythm** : ตวัดไม้ทุกบีต ผู้เล่นมีส่วนร่วมตลอดการต่อสู้
> 2. **เส้นทาง** : จากเดิมมีแค่ Encounter / Elite / Boss เพิ่ม Shop (ร้าน) · Rest (พัก) · Event (สุ่มเหตุการณ์) · Crossing (ข้ามยุค)
> 3. **สกิลวาทยากร** : PASSIVE ติดตัว + SIGNATURE กด SPACE
>    เช่น THE METRONOME : ขนาดไหนก็ถูก คุมแค่จังหวะ · THE APPRENTICE (SPACE) : 4 ตวัด ขนาดไหนก็ถูก
> 4. **สกิลนักดนตรี** : ANNA (ไวโอลิน) บีตของเธอช่วง PERFECT กว้างขึ้น · KLARA (ฟลุต) แรง 2 เท่าบนโน้ต p
> 5. **ศัตรูมีกลไก** : THE MUTE CHOIR (Elite) ปิดเสียงเครื่องดนตรีหนึ่งกลุ่มต่อรอบ + มีโน้ตซ่อน ???
> 6. **Motif** : ของติดตัวทั้งรัน 21 ชิ้น
> 7. **โหมด NORMAL / MAESTRO** : ช้าและง่ายสำหรับมือใหม่ / เร็วและยากตั้งแต่ต้น

- ⚠️ **แก้ข้อมูลผิด** : สไลด์เดิมเขียนว่า skill ของ THE APPRENTICE = "GOOD นับเป็น PERFECT" แต่นั่นคือ **CLOCKWORK ของ THE METRONOME** · ของ APPRENTICE คือ ABSOLUTE PITCH (4 ตวัด ขนาดไหนก็ถูก)
- ⚠️ THE MUTE CHOIR เป็น Elite เจอที่ช่อง Elite ไม่ใช่ "ด่าน event ???" (ผมไม่แน่ใจว่าสไลด์เดิมหมายถึงอะไร เช็กอีกทีได้)

## หน้า 16 — Playtest : จุดประสงค์ + ขั้นตอน
> **จุดประสงค์** : ทดสอบระบบหลักของ prototype และบาลานซ์ แล้วนำ feedback ไปปรับ
> **เป้าของ Prototype** : คนที่ไม่เคยเล่นเกมจังหวะหนักๆ เรียนจากในเกมเอง แล้วเล่นชั้นแรกได้โดยไม่ต้องมีคนอธิบาย
>
> **ขั้นตอน** (เพลย์เทส 25 ก.ย. ผู้เล่น 5 คน + ผู้สังเกต 1)
> 1. ช่วงเตรียมตัวก่อนสู้ — เข้าใจไหม ยากไปไหม
> 2. Tutorial สอนดวล — เข้าใจง่ายไหม
> 3. ดวลจริง — ลื่นไหล ดึงดูดไหม
> 4. สัมภาษณ์ + แบบสอบถาม → นำไปปรับ

- เติม "25 ก.ย. 5 คน" ให้ชัดว่าทดสอบเมื่อไร กับใคร

## หน้า 17 — ชุดคำถาม
เกณฑ์อาจารย์ขอ **"วัดเป็นตัวเลขได้"** · แนะนำเพิ่มคำถามให้คะแนน 1–5 ไว้บนสุด :
> **ให้คะแนน 1–5**
> 1. เข้าใจวิธีเล่นจาก Tutorial ได้เองแค่ไหน
> 2. อ่านโน้ตทัน (ทิศ + ขนาด) แค่ไหน
> 3. ความยากชั้นแรกเหมาะแค่ไหน (1 ง่ายไป · 3 พอดี · 5 ยากไป)
