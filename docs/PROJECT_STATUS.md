## 1. เกมนี้คืออะไร

เกม roguelike แบบ turn-based ผู้เล่นเป็น **คอนดักเตอร์** คุมวงดนตรีสู้กับ **TACET (ความเงียบ)**
หนึ่งรัน = 3 ชั้น ชั้นละ 7–10 ด่าน ด่านสุดท้ายของทุกชั้นคือบอส ชนะบอสชั้น 3 = จบรัน

การต่อสู้แบ่งเป็น 3 ขั้น
1. **เวที (Stage)** — ลากนักดนตรีลงที่นั่ง แถวหน้าแรงแต่เปลืองสตามิน่า แถวหลังถูกแต่เบา
2. **โน้ต (Score)** — เลือกว่าใครเล่นจังหวะไหน จาก 8 จังหวะ โดยดูว่า TACET จะตีจังหวะไหน
3. **ดวล (Duel)** — TACET เล่นห้องละ 4 บีตก่อน แล้วผู้เล่นใช้เมาส์เป็นไม้บาตอง ตวัดตอบ 4 บีตตามท่า 4/4
   ขนาดการตวัด = สั่งให้วงเล่นเบา / ปกติ / แรง พลังสองฝั่งหักกันแล้วดันเส้น
   ดันถึง +100 ชนะทันที โดนดันถึง -100 แพ้ (รายละเอียดหัวข้อ 6)

แก่นของเกมคือ **การบริหารสตามิน่า** สตามิน่าไม่ได้รีเซ็ตต่อการต่อสู้ แต่ลากยาวทั้งรัน

## 6. ระบบที่มีในเกม

### การต่อสู้ — ถามแล้วตอบทีละห้อง (รอบ 3, 23 ก.ย.)
> **รอบ 6 เปลี่ยนแล้ว** : ไม่มีช่วงรอระหว่างห้อง ห้องที่สองของ TACET วิ่งมาระหว่างที่เราตอบห้องแรก และ BPM เป็น 88/100/116
> (ดูหัวข้อ "รอบ 6" ด้านล่าง) ข้อความในหัวข้อนี้เก็บไว้เป็นประวัติ

**1 รอบ = 8 บีต = 2 ห้อง** แต่ละห้องเป็น "วลี" (phrase) ที่มี 2 ช่วง:
- **CALL** — TACET เล่นห้องของมัน 4 บีตก่อน โน้ตแต่ละตัวออกจาก TACET ตรงบีตของมันแล้ววิ่งมา
  **นานหนึ่งห้องพอดี** เลยมาถึงเส้นกลางตรงบีตที่ต้องตอบ โน้ตวิ่งเข้ามาเป็นจังหวะเหมือนเลนเกมดนตรี
  แต่ละโน้ตมีลูกศรทิศการตวัดที่ต้องใช้ตอบ (โน้ตเงียบ = ขีด, โน้ตซ่อน = ?)
- **ANSWER** — ผู้เล่นตวัดตอบ 4 บีตต่อกันตามจังหวะจริง
- **Tempo เร่งขึ้นทุกรอบ** 72 → 84 → 96 BPM (`BattleRules.TempoBpm`)
- จบแต่ละห้องมีภาพหยุดสั้นๆ + จอสั่น (ระหว่างห้องไม่หยุดภาพ เพราะจะทำให้จังหวะเพี้ยน)

**การตวัด**
- **ต้องกดคลิกซ้ายค้าง** ถึงจะนับ ปล่อยปุ่มแล้วเมาส์ไปไหนก็ได้ (ไม้ลดลงเป็นสีจาง)
  ปล่อยปุ่มกลางการตวัด = จบการตวัดตรงนั้น
- เล่นได้ 2 แบบ: กด-ลาก-ปล่อย ทีละบีต หรือกดค้างแล้ววาดรูป 4/4 ต่อเนื่อง (ระบบจับจุดเลี้ยวเป็นบีต)
- ทิศตามท่า 4/4: ลง · ซ้าย · ขวา · ขึ้น ตวัดผิดทิศ = MISS
- ขนาด = คำสั่ง: สั้น (<100px) EASE · กลาง PLAY · ยาว (≥200px) BOOST (มีไม้บรรทัดงอกจากปลายไม้บอกโซน)
- จังหวะนับตอนไม้หยุด/เลี้ยว ตวัดก่อนบีตเกินครึ่งบีต = นับเป็นการเตรียมมือ ไม่นับ
- ไม่ตวัดจนเลยบีต = HESITATE

**SIGNATURE — สูตรตระกูลเครื่องดนตรี** (แนวคิดจาก takt op. Symphony)
- บีตที่ได้ PERFECT/GOOD ให้ "โน้ต" 1 ตัวกับทุกตระกูลที่เล่นในบีตนั้น (สาย / เป่า / ตี) เก็บข้ามรอบได้
- คอนดักเตอร์แต่ละคนมีสูตรไม่เหมือนกัน (`Conductor.Recipe`):

| คอนดักเตอร์ | สาย | เป่า | ตี |
|---|---|---|---|
| THE APPRENTICE | 1 | 1 | 1 |
| THE METRONOME | 2 | 0 | 2 |
| THE INFERNO | 1 | 0 | 3 |
| THE UNHEARING | 3 | 1 | 0 |
| THE FOLK LEADER | 1 | 2 | 1 |

- ตระกูลที่ไม่มีใครในวงเล่น = ข้ามไป (สูตรไม่มีวันเป็นไปไม่ได้) ถ้าวงไม่มีตระกูลในสูตรเลย ทุกตระกูลที่มีต้องได้ 2
- สูตรครบ → กด **Space** → cut-in → การตวัดครั้งถัดไป = PERFECT + BOOST + พลัง ×1.5

**หน้าจอดวล (แนวคิดจาก Deltarune)**
- **แผงวงดนตรีด้านล่าง** กล่องละคน (หน้า ชื่อ แถว ตระกูล) กล่องเป็นสีขาวเมื่อคนนั้นเล่นบีตที่กำลังตอบ
  มีจุด 8 จุดเป็นโน้ตของคนนั้นในรอบนี้ บีตปัจจุบันมีวงล้อม
- **แผง SIGNATURE ด้านซ้าย** หน้าคอนดักเตอร์ + ช่องสูตรแยก 3 ตระกูล สว่างเมื่อพร้อม
- **กล่องข้อความ `* ...`** มุมขวาล่าง พิมพ์ทีละตัว บอกว่าเกิดอะไรขึ้น (ห้องหนัก / มีโน้ตซ่อน / ตาเรา / ผลของห้อง)
- ตัวเลขปะทะเด้งอยู่เหนือวงแหวนสั้นๆ ทุกบีต
- เอาปุ่ม SPEED x1/x2 ออก (จังหวะตอนนี้ผูกกับ BPM แล้ว)

**ปรับหน้าจอรอบ 4 (23 ก.ย.) — ลดความวุ่นวาย**
- **จุดตีอยู่กลางจอคงที่** (x = 640) มีแถบเลนมืดจากจุดตีไปขอบขวา โน้ตวิ่งระยะเท่ากันเสมอ ไม่เบียดกันแล้ว
  (เดิมโน้ตวิ่งไปหาเส้นแบ่งฝั่งที่ขยับตามคะแนน เลยเบียดกันตอนเราชนะ)
- ตัดของซ้ำ: แถบลำดับบีตด้านบน, พัดลม TACET'S PART, ป้าย NEXT, ข้อความ HEAVY/LIGHT และ PLAYS/BOOSTS
- ข้อความเด้ง **อันเดียวต่อบีต** ที่จุดตี เช่น `PERFECT  /  BOOST` สตามิน่ากับแถบดึงเชือกใช้กระพริบแทนตัวเลข
- วงแหวนเหลือแค่วงเป้า + วงที่หด + ลูกศร · ไม้บรรทัดวัดขนาดโชว์เฉพาะตอนกดค้าง
- ด้านบนเหลือ 3 แผง: รอบ/สตามินา · แถบดึงเชือก · ชื่อศัตรู — แผง SIGNATURE ย้ายลงไปรวมแผงล่าง
- **ไม้บาตองเป็นแท่งสี่เหลี่ยม** จับที่เมาส์ แกว่งแบบสปริงเหมือนตวัดดาบ (มีเด้งตอนตวัด) ปล่อยเมาส์แล้วไม้ห้อยลง
  เป็นช่องใส่อาร์ต `Content/Art/Baton/baton.png`
- วงกระแทกตอนเสียงชนเล็กลงและสั้นลง

**เหมือนเดิม**: เกรด PERFECT ×1.2 / GOOD / MISS ×0.7 + เสียสตามิน่า / HESITATE ×0.75 · COMBO +6% ต่อครั้ง สูงสุด +30% ·

### รอบ 6.3 (25 ก.ย.) — ทำให้ SIMPLE

ผู้ใช้ : เอาเสียงชั่วคราวออก · ■ ● ✸ ดูยาก กลับไปใช้ตัวอักษร · ตวัดโอเคแล้ว แต่ "โน้ตและการกระทำที่กำลังมามันงง" · ลองทำให้ simple

**หัวลูกศรทึบติดขอบวงโน้ต** ด้านที่ต้องตวัดไป (ขอบดำ อ่านได้ทุกพื้น) ตรงกับลูกศรนอกวงแหวนตอบ พอโน้ตเข้าวงลูกศรจะเรียงกันพอดี ·

**สอนทีละชั้น** : ชั้น 1 = ตวัดล้วน (Elite/บอสจบรอบด้วย TREMOLO ซึ่งแค่สะบัดรัวๆ) · ชั้น 2 = ศัตรูธรรมดาจบรอบด้วย FERMATA

**ตัดออก** : เสียงชั่วคราวจากโค้ด (`Audio/PlaceholderSound.cs` ลบแล้ว เกมเงียบจนกว่าจะมีไฟล์จริง) · รูป ■ ● ✸ ทั้งหมด ·

## 10. ยังไม่ได้ทำ / ข้อควรรู้

- **อาร์ตทั้งหมด** และ **ไฟล์เสียงทั้งหมด**
- **ทำทีหลังตามที่ผู้ใช้สั่ง** : เมนูหยุดเต็ม + CONTINUE · โหมด Tutorial ที่หน้า title · เซฟ/ปลดล็อก · ปรับใหญ่ห้องซ้อม/เส้นทาง/จัดทีม/จัดจังหวะ (ดูหัวข้อ 0)
- **ตัดทิ้งแล้ว** : โหมดเลือกความยาก · รองรับทัชแพด · ยุค = จังหวะ (4/4, 2/4, 3/4) · เพลงยาวในดวล
- เซฟรันมีแล้ว (รอบ 6) แต่ **ไม่เซฟตรงหน้าผลลัพธ์/เลือก Motif** : ชนะแล้วออกเกมตรงนั้น = CONTINUE กลับไปดวลนั้นใหม่ ·
  ร้านสุ่มของใหม่เมื่อ CONTINUE เข้าร้านเดิม · เซฟมีช่องเดียว
- **ระบบรอบ 6 ยังไม่มีคนเล่นจริง** : 116 BPM + โน้ตคู่อาจเร็วเกินสำหรับเมาส์บางตัว ให้ทำ STROKE TIMING test ก่อนเล่น
- ภาษาไทยในหน้าตั้งค่า **เลือกได้แต่ยังไม่แปล** เพราะฟอนต์ที่ build ไว้มีแต่ตัวอักษรอังกฤษ
- ยังเปลี่ยนปุ่มควบคุมเองไม่ได้
- **ระบบห้อง 4 บีต (รอบ 3) ยังไม่มีคนลองเล่นจริง** ตัวเลขที่น่าจะต้องจูน: `TempoBpm` (72/84/96),
  `PerfectWindow`/`GoodWindow`, และตัวเลขความรู้สึกบนสุดของ `Core/GestureReader.cs`
- ตอน cut-in ของ SIGNATURE เกมหยุดทั้งหมด รวมถึงจังหวะ ถ้ารู้สึกว่าทำให้หลุดจังหวะ (ยิ่งตอนตวัดต่อเนื่อง) อาจย้ายไปเล่นตอนจบห้องแทน
- หน้าจัดจังหวะนักดนตรียังรู้สึก "ไม่ใช่" — คุยทางเลือกไว้แล้ว 3 ทาง (A ท่อนประจำตัวแบบ Incredibox ⭐ / B สั่งสดแบบ Patapon / C การ์ดวลี) ยังไม่ได้ตัดสินใจ
- **ยังไม่มีไฟล์เสียงเลย** ซึ่งน่าจะเป็นเหตุผลใหญ่สุดที่การตวัดยังไม่รู้สึกสนุกเท่าที่ควร
- ผลของท่า SIGNATURE ยังเหมือนกันทุกคอนดักเตอร์ (ต่างกันแค่สูตร) และยังไม่มีระบบเก็บสูตรใหม่ระหว่างรัน
- ภาพมือวาทยากร / ฉากหลังดวล / นักดนตรียืน / cut-in ยังเป็นภาพแทน รออาร์ตจริง
- ฉากเปิดเรื่องยังไม่ทำ (ตัดออกตั้งแต่ตอนวางแผน)
- ความสามารถนักดนตรีและกลไกศัตรูเป็นฐานแรก "ลองทำไปก่อน" ยังไม่ได้เล่นทดสอบจริง
- บอสมีแค่ยุคละ 1 ตัว เจอซ้ำแน่ถ้าเล่นหลายรัน
- **เล่นจริงจนจบรัน (แพ้) แล้ว 1 ครั้ง** เจอบั๊กหน้า Curtain Call แก้แล้ว 23 ก.ย. (ดูหัวข้อ 12) — แต่ยังไม่มีใครเล่นจนชนะบอสสุดท้ายจริง

## 11. เครื่องมือและการสำรองไฟล์

```
เปิดหน้าที่ระบุพร้อมข้อมูลตัวอย่าง แคปเป็น PNG แล้วปิดตัวเอง โดยไม่ยุ่งกับเมาส์/คีย์บอร์ด

Tacetno433.exe --shots simulate --out C:\temp
```
จำลองการต่อสู้หลายพันครั้ง + จำลองการเล่นทั้งรัน แล้วเขียนผลลง `simulate.txt`

recruit bandname route pause view stage score scoretrait scorepairs bargain duel duelcombo duelboss duelcutin duelpause
dueldouble dueltremolo duelfire finale result defeat reward shop shopleave event rest curtain curtainwin
(บางหน้าให้เครื่องมือแกล้งกดปุ่มก่อนแคป ผ่าน `Input.PretendPress` เช่น Esc ของ `pause`/`duelpause`/`titlequit`, Enter ของ `shopleave` ·
`dueldouble`/`dueltremolo`/`finale`/`calibrate` กระโดดไปจังหวะนั้นเลยผ่าน hook สำหรับถ่ายภาพ)

```bash
Tacetno433.exe --shots savecheck --out C:\temp
```
เซฟรัน + ตั้งค่าลงโฟลเดอร์ที่ระบุ (ไม่แตะเซฟจริง) โหลดกลับ แล้วเขียน PASS/FAIL ทุกค่าลง `savecheck.txt` (ผ่านครบ 25 ก.ย.) ·
ตอนแคปภาพเครื่องมือปิดเซฟ (`SaveFile.Enabled = false`) ภาพจึงไม่อ่าน/เขียนเซฟจริง และไม่เปิดเต็มจอตามค่าที่ผู้ใช้เซฟไว้

ตอนแคป เครื่องมือจะขยับ **เมาส์ปลอม** เป็นรูป 4/4 และแกล้งกดปุ่มค้างไว้ (`Input.PretendHeld`)
เพื่อให้เห็นไม้และการตวัดในภาพ — การตวัดในภาพจึงไม่ตรงจังหวะ เห็น WRONG WAY / MISS เป็นเรื่องปกติ
หน้าดวลที่น่าแคป : `duel@150` (ช่วง CALL) · `duelcombo@262` (ช่วง ANSWER)
