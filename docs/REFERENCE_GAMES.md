## 1. Worldless (Noname Studios 2023) : อ้างอิงหลักของงานภาพ

ข้อเท็จจริงที่ใช้ (แหล่งอยู่ในไฟล์ดิบ)
- ทีมเล็ก ทำสไตล์ปกติไม่ไหว ความมินิมอลจึงเกิดจากข้อจำกัด แล้วศิลปินทำให้เป็นโลกของเกม (สัมภาษณ์ Nintendo Life)
- ตัวเอกเป็นรูปทรงแยกชิ้น หัวเป็นลูกแสงฟ้า ไม่เห็นลำตัว ศัตรูเป็นก้อนดำทึบหรือขาวทึบมีแกนเรืองจุดเดียว
- ฉากแต่ละที่เกือบเป็นเฉดเดียว มีสีจัดแค่หนึ่งถึงสองสี ฝั่งเราฟ้า ฝั่งศัตรูส้ม สีบอกฝ่าย
- HUD บางมาก แถบเลือดเอียงบางชิดมุมจอ เกจวงกลมเส้นบางกับเลขเปอร์เซ็นต์ตัวใหญ่บาง ตัวหนังสือแทบไม่มี (เห็นคำเดียวคือ RESISTED)
- การ์ดสัตว์ 3 x 3 : ฉากสีเดี่ยวต่อสัตว์ แกนเรืองจุดเดียว รูปทรงไม่กี่ชิ้นลอยแยกที่บอกที่มา ที่ว่างเยอะ ชื่อตัวพิมพ์ใหญ่เว้นระยะกว้าง ไม่มีกรอบ
- ศัตรูบอกท่าด้วยเส้นนอนเส้นตั้งที่กะพริบ
- **ถูกติเรื่องการสอน** : ลำดับปุ่มของการดูดซ่อนไว้ จุดอ่อนศัตรูไม่อธิบาย แผนที่ไม่นำทาง บทสอนไม่พอ (Game8, Vaporlens, Checkpoint Gaming)

| Worldless ทำ | TACET เปลี่ยนเป็น | อยู่ที่ |
|---|---|---|
| มินิมอลเพราะทีมเล็ก | math art แทนอาร์ตที่ทีมวาดไม่ทัน แต่รูปทรงมาจากเครื่องดนตรีและตำนานของแต่ละคน (simple but symbolic, symbolic but see the origins 13.86) ไม่ใช่รูปทรงนามธรรมล้วน | `Core/Figure*.cs` `Core/LegendArt.cs` |
| แกนเรืองจุดเดียวในทุกสิ่งมีชีวิต | หัวของนักดนตรีเป็นแสงสีธาตุของตัวเอง ศัตรู TACET เป็นเปลือกดำที่ขังแสงขาวไว้ (กลับด้านจาก Worldless ที่ศัตรูมีแกนส้ม) | รอบ 6 ของ math art |
| การ์ดสัตว์ (ฉากสีเดี่ยว แกนเรือง รูปทรงไม่กี่ชิ้น) | PLACE ART : สถานที่ทุกแห่งเป็นฉากเล็กแบบนี้ แต่แต่ละที่ใช้ "สิ่งที่บอกว่าที่นี่คืออะไร" ของเรา (เศษดำรอบแกนขาว = ไฟต์, ชั้นวางกับของเรืองหลายสี = ร้าน, แสงอุ่นกับประกายลอย = ห้องพัก) และ LEGEND ART : ภาพหน้านักดนตรีเป็นหน้าต่างเล็กมีสีของตัวเองไล่ขึ้นจากล่าง | `Core/PlaceArt.cs` `Core/LegendArt.cs` |
| สีบอกฝ่าย (ฟ้าเรา ส้มศัตรู) | โลกกับ TACET ขาวดำเทา ฝั่งผู้เล่นสีธาตุสดของแต่ละคน (กฎสีของ Beta1 29 ต.ค.) การ์ดของวงมีแถบสีของตัวเองที่ขอบซ้าย | การ์ดของวง (C6) |
| HUD แทบไม่มีตัวหนังสือ | **ไม่เอา** เป้าหมายของเรา (13.35) คือเล่นครั้งแรกเข้าใจทันที และ Worldless ถูกติเรื่องนี้ เราจึงคงตัวเลขกับคำสั้นไว้ (LIFE 46 / 54, WORDS EVERYWHERE, WHY NOT) แต่ทำให้บางและเป็นระเบียบ | ทุกหน้า |
| เส้นกะพริบบอกท่าศัตรู | ไม่ใช้เส้น (กฎผู้ใช้ 13.28) ใช้วงเล็งกับเครื่องหมายบนการ์ดแทน (MARKS AND AIM) | หน้าต่อสู้ |

บทเรียน : เกมที่สวยและเรียบที่สุดในกลุ่มนี้ยังถูกติเรื่องการสอน ความสวยจึงไม่ใช่ข้ออ้างให้ตัดคำอธิบาย

## 2. Chaos Zero Nightmare (Smilegate ต.ค. 2025) : ใกล้กับ TACET ที่สุด

## 6. หลักที่สรุปจากทั้งห้าเกม แล้วใช้ในก้อน C

1. **ตัวตนมาก่อน** : ทุกหน้าเห็นว่าใครเป็นใครทันที นักดนตรีมีหน้า (math art) ทุกที่ที่เคยเป็นกรอบว่าง วาทยากรมีเครื่องหมายประจำตัว (sigil) ตามที่ผู้ใช้กำหนด 13.87
2. **สีคือฝ่ายและตัวตน** : โลกกับ TACET ขาวดำ ฝั่งเราสีธาตุของแต่ละคน ใช้สีเดียวกันทุกหน้า
3. **แกนเรืองจุดเดียว** : ทุกฉากทุกตัวมีจุดแสงที่ตาไปหาก่อน
4. **ตัวเลขกับคำสั้นแทนประโยค** และต้องอ่านออกตั้งแต่ครั้งแรก (บทเรียนจาก Worldless กับ Limbus)
5. **ไม่มีกรอบว่าง** : ไม่มีภาพก็เป็นฉาก math art หรือไม่มีอะไรเลย ห้ามเหลือกล่องรอภาพ (ข้อที่ CZN ถูกติ)
6. **ของที่ขยับได้แทนภาพนิ่ง** : ตัวละครใน GUI หายใจ แกว่ง ผมกับผ้าปลิวตามลมของเมาส์ (เมาส์คือไม้บาตอง) เป็นจุดต่างของเราจากเกมกาชาที่ใช้ภาพนิ่ง
