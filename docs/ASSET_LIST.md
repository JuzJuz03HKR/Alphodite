## กติกาทุกภาพ

- **pixel art มีสองขนาด**
  - ฉากต่อสู้ (นักดนตรี ศัตรู ฉากหลัง ภาพ cut in) **ขยาย 2 เท่า** วาดเหมือนจอ 640×360 แล้วเกมแสดงที่ 1280×720
  - หน้าจออื่นทั้งหมด (วาทยากร เสาภาพ หน้า ไอคอน สถานที่ เหตุการณ์ การ์ดห้อง) **ขนาดจริง** 1 พิกเซลของภาพเท่ากับ 1 พิกเซลของจอ 1280×720 แบบภาพ THE UNHEARING ที่มีอยู่แล้ว
  - ขนาดในตารางคือขนาดแคนวาสที่วาดจริง export ขนาดนั้นเลย ไม่ต้องขยายเอง
- **สี** : โลกกับศัตรู (TACET) ขาว ดำ เทา แบบ dramatic ส่วนฝั่งผู้เล่นใช้สีสดได้เต็มที่ (รุ้ง ปริซึม กระจก ขาวสว่าง)
  ตัวละครแต่ละตัวมีสีเดี่ยวของตัวเอง (ตา ไฮไลต์ผม อาวุธ จุดเด่น) บอกรหัส hex ของแต่ละตัวด้วย เพราะ VFX กับ UI ของตัวนั้นจะใช้สีเดียวกัน
- **ไฟล์** PNG พื้นหลังโปร่งใส ขอบคมแบบ pixel (ภาพห้องหรือฉากที่เต็มกรอบไม่ต้องโปร่ง)
- **ห้ามมีตัวหนังสือหรือตัวเลขในภาพ** เกมเขียนเองทั้งหมด และจะแปลไทยทีหลัง
- **ชื่อไฟล์** ตัวพิมพ์เล็ก เว้นวรรคและเครื่องหมายทุกตัวเปลี่ยนเป็น `_` เช่น THE DEVIL'S STRING เป็น `the_devil_s_string` ใช้ชื่อตามตารางตรงตัว ผิดตัวเดียวเกมหาไม่เจอ
- **ส่งงาน**
  - ภาพใน `Content/Art/Battle/` กับ `Content/Art/Ui/` วางไฟล์แล้ว Rebuild ใน Visual Studio ได้เลย ไม่ต้องแก้ `Content.mgcb`
  - ภาพอื่น (วาทยากร สถานที่ เหตุการณ์ การ์ดห้อง ไม้บาตอง) ต้องเพิ่มใน `Tacetno433/Content/Content.mgcb` ด้วย (MGCB Editor แล้ว Add Existing Item) ตารางบอกไว้ทุกชิ้นว่าชิ้นไหนต้องเพิ่ม
  - จะส่งไฟล์ให้ผู้ใช้หรือไอริสวางให้ก็ได้
- **ท่าของตัวละครในฉากต่อสู้** ส่งได้ 2 แบบ (`BATTLE_ART_PLAN.md` ข้อ 8)
  - Aseprite : `<ชื่อ>.png` (sprite sheet) คู่กับ `<ชื่อ>.json` ตั้งชื่อ Tag ตามชื่อท่า เวลาของแต่ละเฟรมตามที่ตั้งใน Aseprite เฟรมที่โดนใส่ใน User Data ของ Tag เช่น `hit 5`
  - ไฟล์แยกเฟรม : `<ชื่อ>_<ท่า>_<เลข>.png` เลขเริ่มที่ 0 เกมเล่น 10 เฟรมต่อวินาที
- **ป้ายในตาราง**
  - ⭐⭐⭐ เห็นตลอดและช่วยให้คนเล่นครั้งแรกอ่านเกมออก ทำก่อน / ⭐⭐ เห็นบ่อย / ⭐ ทำทีหลัง
  - **นิ่ง** ชื่อกับขนาดไม่เปลี่ยนแล้ว วาดได้เลย / **อาจเปลี่ยน** รองานจัดหน้าจอรอบสุดท้าย (GUI) วาดได้ แต่ขนาดหรือกรอบอาจขยับ
  - **ไม่บังคับ** ไม่มีเกมก็ทำงานครบ ระหว่างที่ยังไม่มีภาพ เกมวาดกรอบว่างไว้ตรงที่ภาพจะอยู่ ขนาดเท่าของจริง

## ลำดับที่แนะนำ (ทีมทำคู่ขนานระหว่างที่ไอริสทำระบบ)

1. ไอคอน 29 ชิ้น (ข้อ 4) เล็ก ทำเร็ว และทำให้หน้าต่อสู้อ่านออกทันที ตรงกับเป้าหมาย "คนเล่นครั้งแรกเข้าใจทันที"
2. นักดนตรี 1 คนในฉากต่อสู้ ท่า idle กับ attack แล้วส่งมาก่อน ไอริสจะใช้ทดสอบแสง VFX และเฟรมที่โดน แล้วค่อยทำครบ 5 คน
3. ศัตรูธรรมดา 1 ตัว ท่า idle กับ attack แล้วตามด้วยตัวอื่น
4. ฉากหลังท่อนแรก PRELUDE ชั้น far กับ stage
5. เสาภาพกับหน้าของนักดนตรี 5 คน (หน้า THE AUDITION เป็นหน้าแรกของทุกรัน)
6. วาทยากรอีก 2 คน (gallery กับ face)
7. บอส 6 ตัว ทั้งตัวในฉากและภาพ cut in แล้วฉาก NOCTURNE กับ CODA
8. ที่เหลือ : ภาพ FINALE ของวาทยากร สถานที่ เหตุการณ์ การ์ดห้อง ไอคอนเกม

# ฝ่ายเสียง

## S0. สถานะตอนนี้

- เกมเงียบทั้งเกม ยังไม่มีไฟล์เสียงจริง ตัวโหลดข้ามไฟล์ที่ไม่มีไปเงียบๆ และไม่ใส่เสียงชั่วคราว
- **ไฟต์ของ Beta1 แทบไม่มีจุดเล่นเสียง** ตอนนี้มีแค่เสียงปุ่มกับเพลงไฟต์ (`combo_up` ดังเฉพาะไฟต์ฝึกตอนผ่านบทเรียน) เสียงตี โน้ต ปัด ศัตรู บอส ต้องต่อโค้ดเพิ่ม (ข้อ S3) ทำตอนงานเสียงตามลำดับงาน
- ทิศทางที่ผู้ใช้วางไว้ (`USER_BRIEFS.md` 13.39) : อาวุธผสมเครื่องดนตรี ตอนตีมีเสียงเครื่องดนตรีผสมเสียงอาวุธ
- มีเสียงเครื่องดนตรี 9 ไฟล์ใน `Content/Audio/Instruments/` ทำจากคลัง `SoundLibrary/` เป็นของระบบเพลงตามโน้ตของ Alpha6 ปิดอยู่ (`SoundBank.InstrumentsOn = false`) ไฟต์ Beta1 ไม่ได้เรียกใช้

## กติกาไฟล์เสียง

- เสียงสั้น : WAV 44.1 kHz 16 bit (mono ได้) เสียงเริ่มทันทีที่ต้นไฟล์ ไม่มีช่วงเงียบข้างหน้า เสียงตีกับเสียงโน้ตควรสั้น เพราะโน้ตมาติดกัน
- เพลง : OGG (mp3 ก็ได้) เกมเล่นวนทั้งไฟล์ ท้ายเพลงต้องต่อกับต้นเพลงได้เนียน ไม่ต้องจางท้าย เพลงไม่ต้องตรงจังหวะกับโน้ต เกมไม่ผูกโน้ตกับเพลงแล้ว
- ความดังของทุกไฟล์ใกล้เคียงกัน
- ใส่ไฟล์ใน `Tacetno433/Content/Audio/Sfx/` หรือ `Tacetno433/Content/Audio/Music/` ชื่อตามตาราง แล้วเพิ่มใน `Content.mgcb` (เสียงสั้นใช้ processor "Sound Effect" เพลงใช้ "Song") กด F3 ในเกมดูจำนวนที่โหลดได้
