# 958221 Game Development 1

## สไลด์ 4 — Core Game (กลไกการเล่นหลัก) · ใส่ภาพ `core_game_loop.png`

**ลูปทุกบีต : อ่านโน้ต → ตวัด → ทั้งวงเล่น → ปะทะ**

1. **อ่านโน้ต** TACET เล่นท่อนเพลง โน้ตวิ่งมาตามเลน บอก 3 อย่าง : **ลูกศร** = ทิศตวัด · **ตัวอักษร p / mf / f** = ขนาดตวัด · **วงแหวน** = จังหวะ
2. **ตวัด** คลิกซ้ายค้าง ตวัดตามท่า 4/4 (ลง → ซ้าย → ขวา → ขึ้น) · หยุดตรงวงแหวน = PERFECT (±0.08 วิ) / GOOD (±0.18 วิ) / MISS · ผิดขนาด แรงเหลือ 30%
3. **ทั้งวงเล่น** ทุกคนบนเวทีเล่นโน้ตนั้น ด้วยเสียงเครื่องของตัวเอง ระดับเสียงตามเพลง · **CUE** ตวัดไปฝั่งไหน คนฝั่งนั้นแรง ×1.5 · **SECTION** กลุ่มเครื่องเดียวกัน 2 คน +10% ครบ 3 คน +25%
4. **ปะทะ** พลังวงปะทะโน้ต TACET → ชนะบีตดันเส้น (สูงสุด 8 ต่อโน้ต · Elite ดันได้ 70% · บอส 60%) · แพ้บีต TACET ซัดวง เสีย **ลม (BREATH)** · MISS เสียลม 4 · บีตเงียบ = พัก ได้ลมคืน 12

- **1 ดวล** สูงสุด 3 รอบ · รอบ 1 / 2 / 3 เล่นท่อน 8 บีต 1 / 2 / 3 ครั้ง เร็วขึ้นทุกรอบ
- **ชนะ :** ดันเส้นถึง +100 (วงเล่นท่อนนั้นจนจบ) · FINALE ตอนนำถึง +80 · ครบ 3 รอบเส้นอยู่ฝั่งเรา
- **แพ้ :** ลมหมด · ถูกดันถึง −100 · ครบ 3 รอบเส้นไม่อยู่ฝั่งเรา (ความเงียบตัดเพลง)
- **ท่าพิเศษ :** COMBO PERFECT ติดกันแรงขึ้นทีละ 6% สูงสุด 30% · FORTISSIMO PERFECT 8 ครั้งติด แรง ×1.3 นาน 4 บีต · IN TUNE / COUNTER ตรงเป๊ะ TACET เหลือ 60% / 70% · SIGNATURE (SPACE) ท่าประจำคอนดักเตอร์ 4 ตวัด
- **โน้ตพิเศษมาทีละชั้น :** TREMOLO รัว (Elite / บอส) · FERMATA ค้าง (ชั้น 2) · ✦ โน้ตคู่ (ชั้น 2)
- **ไล่ระดับความยาก :** BPM ชั้น 1 = 80 / 88 / 96 · ชั้น 2 = 88 / 100 / 112 · ชั้น 3 = 96 / 112 / 128 · **2 ดวลแรกของรัน** มีแค่ f กับ p เล่นบีตเว้นบีต · แรงศัตรูตามชั้น ×0.85 / ×1.45 / ×2.45
- **ตัวเลขบาลานซ์ทุกตัวอยู่ไฟล์เดียว** `Data/BattleRules.cs` · กติกาอยู่ `Battle/BattleState.cs` (ไม่มีโค้ดวาด)

## สไลด์ 5 — Gameplay Loop (ลูปทั้งเกม) · ใส่ภาพ `gameplay_loop.png`

1. เมนูหลัก (NEW RUN · CONTINUE · TUTORIAL · HOW TO PLAY)
2. เลือกคอนดักเตอร์ 5 คน
3. เปิดชั้น (MOVEMENT I–III) → เลือกยุค (CLASSICAL · SIAM · ROMANTIC) → รับนักดนตรีเข้าวง
4. เลือกเส้นทาง (ทางแยก 2–4 ทาง) · กด TAB เปิดหน้า THE BAND เลือกใครขึ้นเวที
5. เข้าด่าน : ดวล (ธรรมดา · Elite · บอส) = Core Game · ร้าน · พัก · เหตุการณ์ ??? · CROSSING ข้ามยุค
6. รับรางวัล : Shards · Motif 1 ใน 3 · ลมคืนบางส่วน → วนข้อ 4 จนถึงบอส → ชนะบอสไปชั้นถัดไป
7. Curtain Call สรุปรัน → กลับเมนู

- **1 รัน = 3 ชั้น** ชั้นละ 7–10 ด่าน ด่านสุดท้ายคือบอส · ลม · Shards · Motif · นักดนตรี ติดตัวทั้งรัน · **แพ้ดวลครั้งเดียว = จบรัน**

4. โน้ตเพลงต้องมาจาก score / MIDI ที่ถูกต้อง และต้องเป็นเพลงหมดลิขสิทธิ์
5. build ได้เฉพาะ Windows (ฟอนต์อ้าง path ของ Windows)

## ภาคผนวก — คำตอบเตรียมไว้

- **ต่างจาก osu! / Taiko ยังไง :** เราไม่ได้กดตามโน้ต เรา "นำวง" ทิศและขนาดของไม้คือคำสั่ง · ทั้งวงเล่นตาม · มีชั้น roguelike (คอนดักเตอร์ นักดนตรี Motif) ที่ทำให้แต่ละรันต่างกัน
- **Roguelike ตรงไหน :** รัน 3 ชั้น ทางแยกสุ่ม แพ้แล้วเริ่มใหม่ ของที่เก็บระหว่างรัน (นักดนตรี Motif) เปลี่ยนวิธีเล่น
- **ทำไมใช้เมาส์ :** ท่าตวัดของวาทยากรจริง (ท่า 4/4) คือเอกลักษณ์ของเกม ทิศและขนาดของไม้เป็นคำสั่งได้ในตัว (เวอร์ชันแรก 18 ก.ย. ใช้ปุ่ม F/G/H)
- **ทำไมตัดหน้าวางแผน :** เพลย์เทส 6/6 คนเข้าใจยาก ย้ายความลึกไปไว้ที่ตัวนักดนตรีและคอนดักเตอร์แทน
- **ความยากสำหรับทุกคนทำยังไง :** ไม่มีโหมดความยาก ใช้ curve : 2 ดวลแรกช้าและมีแค่ f/p ความเร็วและแรงศัตรูขึ้นตามชั้น · มีคอนดักเตอร์สำหรับคนเล่นง่าย (METRONOME)
- **เพลงลิขสิทธิ์ :** ใช้เพลงคลาสสิกที่หมดลิขสิทธิ์ (ODE TO JOY, Beethoven 1824) เขียนเป็นตัวโน้ตเอง ไม่ใช้ไฟล์เสียงที่คนอื่นอัด
- **อาร์ตทำไมยังไม่มี :** ตกลงกันว่าไม่ใช้ภาพ AI · ทีมอาร์ตวาดเอง ในเกมเว้นช่องไว้ครบ
