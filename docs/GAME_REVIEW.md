## 2. ด้านออกแบบ — ตัวที่ยกระดับเกมได้มากที่สุด

### 2.1 ให้วงของเราเป็นเพลง (สำคัญที่สุด) · ความยาก M
ปัญหา : เกมจังหวะที่เงียบ และถ้าใส่เพลงเป็นไฟล์ยาวจะไม่ตรงจังหวะ เพราะ
- นาฬิกาดวล (`clock += dt`) ไม่ได้อ่านตำแหน่งเพลง
- BPM เปลี่ยนทุกรอบ 72 → 84 → 96 เพลงไฟล์เดียวตามไม่ได้
- cut-in และ hit-stop หยุดนาฬิกา แต่เพลงเล่นต่อ

ทางที่แนะนำ : เพลงดวลสร้างจากเสียงสั้นที่เล่นตรงบีต (แบบ Incredibox / Patapon)
- บีตของ TACET = เสียงของ TACET (หนักเมื่อ BOOST)
- บีตคำตอบ = เสียงเครื่องดนตรีของคนที่ถูกจัดให้เล่นบีตนั้น ดัง/เบาตาม EASE / PLAY / BOOST
- พื้นหลังเป็น loop กลองหรือ drone เบาๆ ที่เริ่มตรงห้อง (ไฟล์ละ BPM)

ผลพลอยได้ : ไม่มีปัญหาเพลงหลุดจังหวะ · ได้ยินผลของการจัดวง · ต่อยอดหน้าจัดจังหวะทาง A ได้
ทีมต้องเตรียม : เสียงโน้ตสั้น (< 1 วิ) นักดนตรีคนละ 1–3 ไฟล์ · เสียง TACET 3 ไฟล์ · loop พื้น 1–3 ไฟล์

### 2.2 ให้ CALL บอกว่า TACET จะทำอะไร · ความยาก S
ปัญหา : TACET สุ่ม BOOST / EASE ไว้ตั้งแต่ต้นรอบ (`BattleState.RollEnemyChoice`) แต่ผู้เล่นรู้ตอนปะทะ
(`DuelScreen.StartClash`) ทั้งที่ CALL คือช่วงที่ TACET เล่นให้ฟังก่อน
การเลือกขนาดตวัดจึงเหลือแค่ "สตามิน่าพอก็ BOOST"

ทางแก้ : โน้ตในเลนแสดงท่าของ TACET — BOOST = โน้ตใหญ่มีหนาม, EASE = โน้ตจางบาง (โน้ต ??? ยังเป็นความลับเหมือนเดิม)
คำตอบจะมีความหมาย : ตอบ BOOST ด้วย BOOST, TACET ผ่อนก็ผ่อนตามเพื่อเก็บแรง
(อาจมีโบนัสเล็กเมื่อ "ตามไดนามิกส์ถูก" = เมล็ดของ route ประสานเสียงกับความเงียบ)

## 3. หน้าจอและความรู้สึก

- ป้ายภาพแทน "ART / HAND", "ART / ENEMY", "ART / STAGE SIAM", "FACE ART", "ART" มีเกือบทุกหน้า ภาพพรีเซนต์ดูไม่เสร็จ → สวิตช์ปิดป้ายทั้งหมดที่เดียว (S)
- ตัวหนังสือเล็กสีเทาบนดำเยอะ (`TextSize.Tiny` + `LineGrey`) บนโปรเจกเตอร์จะอ่านไม่ออก → ขยายขนาดขั้นต่ำ / เพิ่มความสว่าง (S)
- หน้าดวล : วงแหวนเริ่มรัศมี 140 ทับนักดนตรีคนที่สาม · โน้ตในเลนเล็ก (รัศมี 20–42 บนเลนยาว 640 px) → ขยายโน้ตที่กำลังจะถึงตอน ANSWER · ให้ทุกอย่างเต้นตาม BPM (แผนเดิม)
- หน้าผลลัพธ์บอกแค่ตัวเลข → เพิ่มแถบ 8 บีต × รอบ บอกบีตไหนชนะ/แพ้ เหมือนโน้ตที่ถูกตรวจ ช่วยให้เรียนรู้จากแผน (M)
- เปลี่ยนหน้าแบบม่านเวทีแทนเฟดดำ (ดู `DESIGN_RESEARCH.md`) (S–M)
