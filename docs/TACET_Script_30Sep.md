# TACET 4'33 — บทพูด + ข้อความปรับสไลด์ (นำเสนอ 30 ก.ย.)

รวมประมาณ 10 นาที · **[ปรับ]** = แก้ข้อความบนสไลด์ · **[พูด]** = บทพูดสั้นๆ · ถ้าไม่มี [ปรับ] แปลว่าสไลด์ใช้ได้แล้ว

---

### สไลด์ 1 – ปก (10 วิ)
**[พูด]** "สวัสดีครับ พวกเราทีม Alphodite ขอนำเสนอเกม TACET 4'33 — การดวลกับความเงียบครับ"

### สไลด์ 2 – ทีม (10 วิ)
**[พูด]** แนะนำชื่อ + หน้าที่คนละ 1 คำ (โค้ด / อาร์ต / เสียง / ดีไซน์)

### สไลด์ 3 – What is this Game? (40 วิ)
**[ปรับ]**
- Genre : **Roguelike + Rhythm** (ตัด "Planing team" ออก ตอนนี้ไม่มีการจัดทีมก่อนสู้แล้ว)
- แนวคิดหลัก : **"You do not play the notes. You lead the band that does."**
  (ประโยคเดิม "You decide who does." ไม่ตรงกับเกมแล้ว เพราะตอนนี้ทั้งวงเล่นทุกโน้ต)
- ผู้เล่นเป็น **วาทยากร** ใช้เมาส์เป็นไม้บาตอง คุมวงดนตรีสู้กับ **TACET** ความเงียบที่กลืนโลก
- วิธีเล่น : อ่านโน้ต → ตวัดไม้ให้ถูกทิศ ถูกขนาด ตรงจังหวะ → วงเล่นเพลง → ดันความเงียบถอยกลับไป
- คำผิดที่ต้องแก้ : เปน → เป็น · tecet → TACET · เพือ → เพื่อ

**[พูด]** "เกมเราเป็นเกมจังหวะผสมโรคไลค์ครับ ผู้เล่นเป็นวาทยากร ใช้เมาส์เป็นไม้บาตอง ไม่ได้กดโน้ตเอง แต่สะบัดไม้ให้วงเล่นแทน ถ้าเล่นดี เสียงดนตรีจะดันความเงียบถอยกลับไป"

### สไลด์ 4 – Story (40 วิ)
**[ปรับ]** (แทนข้อความเดิม)
> ในโลกที่เสียงเพลงกำลังถูกลืม ความเงียบที่ชื่อ **TACET** กลืนกินบทเพลงไปทีละยุค
> **Endchestra** วงออร์เคสตราสุดท้ายที่ยังเหลืออยู่ จึงเรียกวาทยากรระดับตำนานกลับมา
> ให้เดินทางย้อนไปใน 3 ยุค — **Classical · Siam · Romantic** — รวบรวมนักดนตรี
> แล้วบรรเลงไล่ความเงียบกลับไป ก่อนที่ดนตรีจะหายไปตลอดกาล

คำผิด : tecet → TACET · ทำไห้ → ทำให้

**[พูด]** อ่านกล่องข้อความตามนี้ได้เลย แล้วปิดด้วย "ชื่อเกม 4'33 มาจากเพลงของ John Cage ที่ทั้งเพลงคือความเงียบ ส่วนเกมเราคือการทำลายความเงียบนั้นครับ"

### สไลด์ 5–7 – Game Reference (40 วิ รวม 3 หน้า)
**[ปรับ]** Mush dash → **Muse Dash** · Roguelik → **Roguelike** · ใต้แต่ละกลุ่มใส่บรรทัดเดียวว่าเอาอะไรมา (ตามบทพูดข้างล่าง)

**[พูด]** "เราไม่ได้ลอกเกม แต่หยิบระบบเฉพาะส่วนมาใช้ครับ
- **Rhythm** (Muse Dash, Taiko, D4DJ, DIVA, Project Sekai, DJMAX, Metal: Hellsinger) : การอ่านโน้ต จังหวะ เกรด PERFECT/GOOD และเอฟเฟกต์ตอนตีโดน
- **Roguelike** (Hades, Slay the Spire, Balatro, Darkest Dungeon, Limbus Company) : แผนที่เลือกทาง ของติดตัวทั้งรัน การสร้างวง และแพ้แล้วเริ่มใหม่
- **UI / ธีม** (Arknights, Stella Sora, takt op. Symphony) : หน้าตาเมนู การเปลี่ยนหน้า และธีมดนตรีเป็นพลัง"

### สไลด์ 8 – Game Loop (30 วิ)
**[ปรับ]** "เปดชัน / ชัน" → **เปิดชั้น / ชั้น** · "Core Gamr Loop" → **Core Game Loop**

**[พูด]** "หนึ่งรันเริ่มจากเลือกวาทยากร แล้วเปิดชั้น เลือกยุคและรับนักดนตรี จากนั้นเลือกทางไปเรื่อยๆ ดวล ร้าน พัก เหตุการณ์ จนเจอบอส ชนะบอสก็ไปชั้นถัดไป ครบ 3 ชั้นชนะเกม ถ้าแพ้ต้องเริ่มใหม่แบบโรคไลค์ครับ"

### สไลด์ 9 – Core Game Loop (30 วิ)
**[ปรับ]** "จุนสุด" → **จนสุด** · "ขวาด" → **ขนาด** · "หมดทีมลมก่อนแพ้" → **ลมหมดก่อน = แพ้**

**[พูด]** "ทุกบีตมี 4 ขั้นครับ อ่านโน้ต ลูกศรบอกทิศ ตัวอักษรบอกขนาด p เล็ก mf กลาง f ใหญ่ → ตวัดไม้ให้ตรงจังหวะ → ทั้งวงเล่นโน้ตนั้น → ชนะบีตดันเส้นเข้าหาความเงียบ แพ้บีตเสียลม ดันจนสุดชนะ ลมหมดแพ้"

### สไลด์ 10–11 – ภาพเกม / คลิป (1–2 นาที, เปิดเกมเล่นให้ดู)
**[พูด ระหว่างเล่น]**
1. "หน้าเลือกวาทยากร มุมขวาล่างเลือกความยากได้ NORMAL หรือ MAESTRO"
2. "นี่คือหน้าเส้นทาง เลือกได้ว่าจะไปดวล ร้าน หรือพัก"
3. (เข้าดวล) "โน้ตวิ่งมาจากฝั่งความเงียบ ผมสะบัดตามลูกศรและขนาด ... ถูกต้อง วงเล่น เส้นดันไปข้างหน้า"
4. "ถ้าชนะกลางเพลง วงจะเล่นท่อนนั้นต่อจนจบ"
5. "ตอนนี้เสียงปิดไว้ เพราะไฟล์เสียงยังไม่ลงตัว เดี๋ยวจะพูดในส่วนปัญหาครับ"

### สไลด์ 12–13 – Sprint Planning (40 วิ)
**[พูด]** "สปรินต์นี้ 26–29 ก.ย. เราแบ่งงานเป็นก้อนรายวัน แต่ละวันแยก branch ใน GitHub (Alpha3 ถึง Alpha6) ไม่ให้งานพังกัน ส่วนอีก 4 สัปดาห์ข้างหน้า :
สัปดาห์ 1 เสียงและเพลงบอส + เพลย์เทส · สัปดาห์ 2 อาร์ตตัวละคร ศัตรู ฉาก · สัปดาห์ 3 เนื้อหา · สัปดาห์ 4 VFX และขัดเกลาครับ"

### สไลด์ 14 – Product Backlog (30 วิ)
**[พูด]** "สิ่งที่เสร็จแล้วคือระบบเกมทั้งลูป 3 ชั้น ระบบดวลด้วยไม้บาตอง ลมเป็นเลือด ไล่ระดับความยาก และตัวจำลองบาลานซ์ · ที่กำลังทำคือเสียงและเพลง · ที่ยังไม่เสร็จคืออาร์ตส่วนใหญ่ และวาทยากร 6 คนตามเนื้อเรื่องครับ"

### สไลด์ 15 – Game Design (30 วิ)
**[ปรับ]** Genre เหมือนสไลด์ 3 (ตัด Planing team) · tecet → TACET · เพิ่มข้อ **4. โหมด NORMAL / MAESTRO** (ง่ายช้า / ยากตั้งแต่ต้น)

**[พูด]** "ระบบหลักที่เพิ่มในรอบนี้มี 4 อย่าง : ระบบจังหวะให้ผู้เล่นมีส่วนร่วมตลอด · เส้นทางที่มีร้าน พัก เหตุการณ์ ข้ามยุค · สกิลของวาทยากรที่กด SPACE ได้ · และโหมดความยาก 2 แบบครับ"

### สไลด์ 16 – Playtest : จุดประสงค์ + ขั้นตอน (30 วิ)
**[พูด]** "เป้าเพลย์เทสคือ คนที่ไม่เคยเล่นเกมจังหวะหนักๆ ต้องเรียนจากในเกมเองได้ และเล่นชั้นแรกได้โดยไม่ต้องมีคนอธิบาย เราทดสอบ 3 ส่วน : การเตรียมตัวก่อนสู้ · Tutorial สอนดวล · และการเล่นจริงครับ"

### สไลด์ 17 – ชุดคำถาม (20 วิ)
**[พูด]** "คำถามแบ่งเป็นระหว่างเล่น คำถามทั่วไป และคำถามเรื่องกติกาและหน้าจอ ให้คะแนนเป็นตัวเลข จะได้เทียบก่อน-หลังปรับได้ครับ"

### สไลด์ 18 – ผลเพลย์เทส (30 วิ)
**[พูด]** "ครึ่งหนึ่งสนใจซื้อ เพราะชอบการตวัดไม้กับความแปลกใหม่ · อีกส่วนรอดู Tutorial, UI และบาลานซ์ก่อน · สิ่งที่เราแก้ตามผลแล้วคือ ตัด Tutorial ให้สั้นลง ลดตัวหนังสือ ทำความยากค่อยๆ ขึ้น และเพิ่มโหมด NORMAL ครับ"

### สไลด์ 19 – Difficulties & Advice (40 วิ)
**[ปรับ]** (ข้อมูลเก่าไม่ตรงแล้ว)
- "ภายในเกมยังไม่มีภาพและเสียง" → **"อาร์ตยังไม่ครบ · เสียงต่อแล้วแต่ยังปิดไว้ เพราะเสียงยังไม่ลงตัว"**
- "เกมที่ไม่มีโหมดเลือกความยาก ควรช่วยมือใหม่แบบไหน" → **"เพิ่มโหมด NORMAL / MAESTRO แล้ว · อยากได้คำแนะนำว่าควรช่วยมือใหม่เพิ่มแบบไหน"**

**[พูด]** "ปัญหาที่เจอคือ เกมจังหวะที่ยังไม่มีเสียงทำให้ความรู้สึกหายไปเยอะ · ความยากตอนนี้ยืนยันได้แค่ด้วยตัวจำลอง ยังไม่ได้เทสกับคนจริงในเวอร์ชันนี้ · และเราเปลี่ยนระบบใหญ่หลายรอบในสปรินต์เดียว · อยากขอคำแนะนำอาจารย์เรื่องการช่วยผู้เล่นมือใหม่ และการทำเพลงจาก score ครับ ขอบคุณครับ"
