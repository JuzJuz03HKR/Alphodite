## 3. ตัวละครหลัก (lore จากผู้ใช้ 29 ก.ย., เนื้อเรื่องยังไม่นิ่ง)

**Hollow** = จุดที่ถูกความว่างเปล่าและสีดำกลืนกิน · วาทยากร (maestro) 6 คนที่ผู้เล่นเลือกได้ :

| วาทยากร | ร่าง Hollow | ไม้บาตอง |
|---|---|---|
| Fanny Mendelssohn กับเงาของ Felix | ไร้ชื่อ มีสองคนในคนเดียวซ้อนทับกัน | 12 สี |
| Jean-Baptiste Lully | ไร้ขา ต้องถือไม้เท้า | ธีมดวงอาทิตย์ |
| J. S. Bach | ไร้ตา มีผ้าพันตา | ธีมเซราฟิมที่สลักอักษร |
| W. A. Mozart | ไร้แขนขวา ไร้เงา | ธีมขนนก มีนกเกาะหัว |
| Niccolò Paganini | ไร้อก อกเป็นรู รูปร่างค่อนไปทางปีศาจ | ธีมปีศาจและไวโอลิน |
| L. v. Beethoven | ไร้หู ใส่หนามผลึกสีดำกึ่งมงกุฎแทงเข้าหู สื่อถึงราชาและทรราช | สายฟ้า |

- ผู้ใช้ : "ลองเอาร่าง alter ego หรือศัตรูคู่แค้นของแต่ละคนแล้วเอาเพลงมาใช้ … ร่างมืดของแต่ละคนมาใช้เป็นศัตรูก็คิดว่าเท่ดี … เกมเรามีศัตรูข้างทาง กับ boss ใหญ่"
- Claude เห็นว่าบอสเดิมตรงอยู่แล้ว : REQUIEM = Mozart · THE DEVIL'S STRING = Paganini · THE NAMELESS MASTER = Fanny (ยังไม่ได้เปลี่ยนในเกม)
- ⚠️ วาทยากรในเกมตอนนี้ยังเป็น 5 คนเดิม (APPRENTICE · METRONOME = Bach · INFERNO = Berlioz · UNHEARING = Beethoven · FOLK LEADER = Bartók) ต้องคุยก่อนเปลี่ยน
- เพลงที่ทำแล้ว : ODE TO JOY (Beethoven) ที่ศัตรูข้างทาง 4 ตัว · Caprice 24 (Paganini) ยังไม่ทำ เพราะเว็บโน้ตเพลงถูกบล็อก ไม่แต่งจากความจำ → รอทีมส่ง score/MIDI

## 6. ข้อเสนอของ Claude ที่ผู้ใช้ตอบ "แนะนำ" (29 ก.ย. เช้า, ย่อ)
