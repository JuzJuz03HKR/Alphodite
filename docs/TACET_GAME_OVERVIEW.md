## 1. เกมนี้คืออะไร (พูดใน 30 วินาที)

- **แนว** : roguelike + rhythm (เกมจังหวะ) · ผู้เล่นเป็น **วาทยากร (conductor)** ใช้ **เมาส์เป็นไม้บาตอง**
- **ศัตรู** : **TACET** = "ความเงียบ" (คำว่า tacet ในโน้ตดนตรีแปลว่า "เงียบ ไม่ต้องเล่น") ที่กลืนโลกดนตรี
- **ชื่อเกม** : *4'33"* คือเพลงของ John Cage ที่ทั้งเพลงคือความเงียบ → เกมคือการ "ทำลายความเงียบ"
- **ธีมภาพ** : ขาวดำ แนว Limbus Company Canto 10 "Hollow" (ดวงอาทิตย์ดำ ขอบแสงขาว รอยแยกมิติ)
- **ประโยคเดียว** : *"โน้ตบอกทุกอย่าง — ตวัดตามทิศ ตามขนาด ตรงจังหวะ แล้วทั้งวงจะเล่นให้"*

## 2. Core Game Loop (ทุกบีตในการดวล)

แผนภาพ : `docs/diagrams/core_game_loop.png`

1. **อ่านโน้ต** : หัวลูกศรที่ขอบวงกลม = ทิศที่ต้องตวัด · ตัวอักษร = ขนาดตวัด (**p** เล็ก · **mf** กลาง · **f** ใหญ่)
2. **ตวัดไม้บาตอง** : กดคลิกซ้ายค้าง แล้วสะบัดตามท่า 4/4 (ลง-ซ้าย-ขวา-ขึ้น) ให้หยุดตอนวงแหวนหุบ
3. **วงเล่นเพลง** : นักดนตรีทุกคนบนเวทีเล่นโน้ตนั้นพร้อมกัน
4. **ดันความเงียบ** : ชนะบีต = ดันเส้นเข้าหา TACET · แพ้บีต = วงเสียลม (breath)

**จบดวลเมื่อ** : ดันเส้นถึง +100 = ชนะ · ลมหมดหรือถูกดันถึง −100 = แพ้ · ครบ 3 รอบ ใครนำชนะ

## 3. Gameplay Loop (1 รัน)

แผนภาพ : `docs/diagrams/gameplay_loop.png`

1. **เมนูหลัก** : เริ่มเกม · TUTORIAL · HOW TO PLAY · ตั้งค่า
2. **เลือกคอนดักเตอร์** (5 คน สไตล์ต่างกัน) + **เลือกโหมด NORMAL / MAESTRO**
3. **เปิดชั้นใหม่** : เลือกยุค (CLASSICAL · SIAM · ROMANTIC) แล้วได้นักดนตรีจากยุคนั้น
4. **เลือกทาง** บนถนนของชั้น : ดวล · Elite · ร้าน · พัก · เหตุการณ์ (?) · บอส
5. **ดวล** (Core Game Loop)
6. **รับรางวัล** : Shards (เงิน) · Motif (ของติดตัว) · นักดนตรีใหม่ · ลมคืน 30%
7. วนข้อ 4–6 จนเจอ **บอสของชั้น** → ชนะแล้วไปชั้นถัดไป (ทั้งหมด **3 ชั้น**)
8. **จบรัน** : หน้า Curtain Call (สรุปผล เส้นทางที่เดิน) → กลับเมนู · แพ้ = เซฟรันถูกลบ (แบบ roguelike)

## 4. กติกาการดวล (ละเอียด)

| กติกา | ทำงานยังไง |
|---|---|
| **ท่อนของ TACET** | TACET เล่นท่อนละ 8 บีต (2 ห้อง 4/4) โน้ตเลื่อนเข้ามาในเลน ผู้เล่นตอบทีละบีตต่อเนื่อง ไม่มีช่วงรอ |
| **ขนาดตวัด** | ตรงตัวอักษร = แรงเต็ม · ผิดขนาด = เหลือ 50% (NORMAL) / 30% (MAESTRO) |
| **ความแม่นยำ** | PERFECT / GOOD / MISS ตามเวลาที่ไม้หยุด (บอก EARLY / LATE ด้วย) · MISS เสียลม 4 |
| **ทั้งวงเล่น** | ทุกคนบนเวทีเล่นทุกโน้ตที่ตวัดโดน |
| **CUE** | นักดนตรีแต่ละคนมีลูกศรฝั่งของตัวเอง (ซ้าย / กลาง / ขวา ตามที่นั่งในวงจริง) ไม้ตวัดไปฝั่งไหน คนฝั่งนั้นแรง ×1.5 |
| **SECTION** | เครื่องกลุ่มเดียวกันบนเวที 2 คน +10% · ครบ 3 คน +25% |
| **IN TUNE / COUNTER** | ตรงเวลา + ตรงขนาด = โน้ต TACET เหลือ 60% · PERFECT f ตอบโน้ต f จริง = COUNTER |
| **ลม (BREATH)** | = เลือด · ตวัดไม่เสียลม · เสียเมื่อ TACET ชนะบีต · **บีตเงียบปล่อยผ่าน = พัก +12** |
| **เส้นดัน (คลื่นเสียง)** | ส่วนต่างพลังต่อบีตดันเส้น (โน้ตเดียวดันได้ไม่เกิน 8) · Elite / บอสดันยากกว่า |
| **REPEATS** | รอบ 1 / 2 / 3 เล่นท่อนวน 1 / 2 / 3 ครั้ง ยิ่งรอบหลังยิ่งเร็ว (BPM สูงขึ้น) |
| **FORTISSIMO** | PERFECT ติดกัน 8 ครั้ง → วงลุกเป็นไฟ แรง ×1.3 อีก 4 บีต |
| **FINALE** | จบรอบแล้วเส้นอยู่ ≥ 80 → ตวัดท่า 4/4 ตรงจังหวะ 4 ครั้ง จบดวลทันที |
| **SIGNATURE** | PERFECT เก็บ "โน้ตสูตร" ครบแล้วกด **SPACE** = ท่าพิเศษของคอนดักเตอร์ อยู่ 4 ตวัด |
| **OUTRO** | ชนะกลางท่อน → วงเล่นท่อนนั้นต่อเองจนจบ แล้วค่อยจบดวล · แพ้ = เพลงถูกความเงียบตัด |

### โน้ต 4 ชนิด (ล็อกไว้ เพื่อให้ SIMPLE)
1. **ตวัด** : วงกลม + ตัวอักษร f/mf/p + หัวลูกศร
2. **TREMOLO (รัว)** : แถบซิกแซก → เขย่าไม้ให้เร็วที่สุด (Elite/บอสจบรอบด้วยรัว)
3. **FERMATA (ค้าง)** : โน้ตใต้ส่วนโค้ง → ตวัดแล้วค้างไม้นิ่งๆ (ชั้น 2)
4. **ประกาย ✦ (โน้ตคู่)** : ตวัดซ้ำอีกครั้งครึ่งบีตหลัง ทิศไหนก็ได้ (ชั้น 2)

## 5. ความยาก : NORMAL / MAESTRO (เลือกที่หน้าเลือกคอนดักเตอร์ กด M)

| | NORMAL | MAESTRO |
|---|---|---|
| ความเร็ว (BPM) ชั้น 1 / 2 / 3 | 70-84 / 80-100 / 88-112 | 96 / 112 / 128 ทุกชั้น |
| ดวลเริ่มต้นแบบง่าย (มีแค่ f/p) | 3 ดวลแรก | ไม่มี |
| โน้ตพิเศษ | ค่อยๆ มาทีละชั้น | มาตั้งแต่ชั้น 1 |
| ช่วงเวลา PERFECT / GOOD | ±0.10 / ±0.22 วิ | ±0.08 / ±0.18 วิ |
| ผลจำลอง (ผู้เล่นเก่ง / ทั่วไป ชนะทั้งรัน) | 92% / 62% | 64% / 14% |

- ไล่ระดับยาก (learning curve) : ชั้นแรกช้าและมีแค่ f/p → ค่อยเพิ่ม mf, รัว, ค้าง, โน้ตคู่ และศัตรูแรงขึ้นตามชั้น
- **สอนตอนเจอครั้งแรก** (TEACH NOTES) : ของใหม่ขึ้นป้ายสั้นๆ ในดวล เช่น `ZIGZAG = ROLL : SHAKE FAST`

## 8. สถานะตอนนี้ (ตอบตรงๆ ถ้าอาจารย์ถาม)

- **ระบบเกมเล่นได้ครบลูป** : เมนู → เลือกคอนดักเตอร์ → 3 ชั้น → Curtain Call
- **อาร์ต** : ส่วนใหญ่ยังเป็นกรอบว่าง (placeholder) · มีภาพ THE UNHEARING (แกลเลอรี + หน้า) และตัวละครนักดนตรี (รูปเดียวกันทุกคน)
- **เสียง** : ต่อไฟล์เครื่องดนตรีแล้ว 9 เสียง แต่ **ปิดไว้** เพราะยังไม่เพราะพอ (เปิดได้บรรทัดเดียว)
- **บาลานซ์** : จูนด้วยตัวจำลองในโค้ด (เล่นเองหลายพันรอบ) · ยังไม่ได้เพลย์เทสรอบ 15 กับคนจริง
- **ขนาดโค้ด** : 77 ไฟล์ C# · ~19,900 บรรทัด
- **ความคืบหน้า (ประมาณ)** : ระบบเกม ~85–90% · ทั้งโปรเจกต์รวมอาร์ต/เสียง/เนื้อหา ~55%

## 9. คำถามที่อาจโดนถาม (เตรียมคำตอบ)

- **ทำไมใช้เมาส์เป็นไม้บาตอง?** → ให้ความรู้สึกคุมวงจริง ท่า 4/4 ของวาทยากรจริง ตวัดใหญ่ = ดัง
- **ต่างจากเกมจังหวะทั่วไปยังไง?** → ไม่ได้แค่กดตามโน้ต ต้องเลือกขนาด ทิศ และจัดวง + มีชั้น roguelike (Motif นักดนตรี คอนดักเตอร์)
- **ทำไมขาวดำ?** → ธีม "ความเงียบกลืนสี" และให้อ่านโน้ตง่าย · สีเน้นเปลี่ยนได้จุดเดียวในโค้ด
- **วัดความยากยังไง?** → ตัวจำลองในเกม (`--shots simulate` / `audit`) เล่นหลายพันรอบด้วยผู้เล่นหลายระดับ
- **เพลงลิขสิทธิ์?** → ใช้เพลงคลาสสิกที่ผู้แต่งเสียชีวิตนานแล้ว (public domain) เขียนโน้ตเอง ไม่ใช้ไฟล์อัดเสียงของคนอื่น
