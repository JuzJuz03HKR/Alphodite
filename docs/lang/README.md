# ภาษาไทยของ TACET 4'33 (ก้อน F3, 2 พ.ย. 2026)

## เกมแสดงภาษาไทยยังไง
- **คำแปลอยู่ไฟล์เดียว** : `Tacetno433/Content/Text/thai.txt` บรรทัดละคู่ `อังกฤษ<TAB>ไทย` อังกฤษต้องตรงกับในเกมทุกตัวอักษร บรรทัดไหนไม่มีในไฟล์ = ยังเป็นอังกฤษ
- ชื่อ (PAGANINI, CAPRICE No. 24, ชื่อบอส ชื่อ GIFT) กับคำกติกา (BURN, FINALE, BREATH, PERFECT ...) **ตั้งใจไม่แปล** ตามที่ผู้ใช้บอกว่าคำเฉพาะใช้เป็นชื่อหรือหัวข้อ (13.39) แปลแต่ประโยคอธิบาย คำสั่ง บทพูด
- `Data/Lang.cs` : ตอนเริ่มเกมสลับข้อความในข้อมูลของเกมเป็นไทย (`Apply`) และทุกข้อความที่วาดผ่าน `Gfx` ถูกแปลก่อนวาด (`Of`)
- `Core/ThaiText.cs` : ฟอนต์ไทยคู่ของแต่ละฟอนต์ (Trirong กับ Chakra Petch) และการจัดสระวรรณยุกต์เอง (MonoGame ไม่มีระบบจัดให้)
- เปลี่ยนภาษาที่หน้า SETTINGS แถว LANGUAGE ออกจากหน้าแล้วเกมเปิดใหม่เอง

## เพิ่มหรือแก้คำแปล
- แก้ไฟล์ `thai.txt` ตรงๆ ได้เลย (Rebuild แล้วเห็นผล) / ภาษาไทยยาวไม่มีช่องว่าง ใส่ช่องว่างระหว่างวลีให้ตัดบรรทัดได้
- หาข้อความที่ยังไม่แปล (ในแชท cloud หรือ Debug build) :
  1. `--shots <หน้าต่างๆ>@25 --seen --out <โฟลเดอร์>` ได้ `seen.txt` ข้อความที่ทุกหน้าวาดจริง
  2. `--shots textdump --out <โฟลเดอร์>` ได้ `textdump.txt` ข้อความทั้งหมดในข้อมูลของเกม
  3. `python3 docs/lang/make_keys.py <seen.txt> <textdump.txt>` ได้ `docs/lang/keys.txt` บรรทัดที่มี `+` แปลแล้ว
- `docs/lang/batches/` : ชุดคำแปลที่ใส่ไปแล้ว (`keysN.txt` รายการอังกฤษตอนนั้น `bN.tsv` เลขบรรทัดกับคำแปล `merge.py` ใส่ลง `thai.txt` โดยไม่ต้องพิมพ์อังกฤษซ้ำ)
- ภาพโหมดไทย : `--thai` ต่อท้ายคำสั่งแคป
- เปลี่ยนไฟล์ฟอนต์ไทย : รัน `python3 docs/lang/thai_marks.py` แล้วเอาตารางไปแทน FONT TABLE ใน `Core/ThaiText.cs`
