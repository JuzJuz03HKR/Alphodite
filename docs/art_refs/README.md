# ภาพอ้างอิงแนวอาร์ต (ไม่ใช่ asset ของเกม)

ผู้ใช้อนุญาต 1 พ.ย. (`USER_BRIEFS.md` 13.84) ให้เก็บภาพอ้างอิงไว้ใน repo **ให้ไอริสดูตอนทำงานเท่านั้น**
ห้ามใส่ภาพพวกนี้ลงในเกม ห้ามใช้ทำ build ห้ามแก้ไขแล้วใช้ต่อ เป็นงานของเจ้าของแต่ละราย ใช้เป็นแนวเท่านั้นและต้องเปลี่ยนให้เป็นของ TACET (13.30)

| ไฟล์ | คืออะไร | เจ้าของ |
|---|---|---|
| `worldless_01.png` | ฉากม่วงชมพู ตัวผู้เล่นลูกแสง + ดาบ ศัตรูเศษดำแกนส้ม พื้นสะท้อน | Worldless (Noname Studios) |
| `worldless_02.webp` | ศัตรูเงาดำบล็อกในกรอบเพชรส้ม ตาใหญ่ในวงแหวน | Worldless (Noname Studios) |
| `worldless_03.png` | คนเงาขาวยิงลำแสง ฉากแดง | Worldless (Noname Studios) |
| `worldless_04.webp` | เงาขาวหยักกับสัตว์ดำคลาน (มีลายเซ็นมุมขวาล่าง น่าจะเป็นแฟนอาร์ต) | ไม่แน่ชัด |
| `worldless_05.webp` | บอสขาวปีกเสี้ยว หัววงแหวนฟ้า พื้นสะท้อน UI x100% | Worldless (Noname Studios) |

ภาพอ้างอิงชุดอื่นที่ผู้ใช้ส่งระหว่างที่ไอริสทำงาน ไม่ได้ถูกเก็บเป็นไฟล์ในเครื่อง บรรยายไว้ใน `docs/USER_BRIEFS.md` 13.79 13.81 13.83
ถ้าอยากให้เก็บเป็นไฟล์ ส่งภาพในข้อความตอนที่ไอริสไม่ได้ทำงานอยู่ (ภาพที่มากับข้อความแบบนั้นระบบเก็บเป็นไฟล์ให้)
