# แผนอาร์ตของหน้าจอ (UI Art Plan)

เริ่ม 29 ต.ค. 2026 ใช้คู่กับ `docs/SCREENS_LEVEL_UP.md` (ข้อ 6) และ `docs/BATTLE_ART_PLAN.md` (ภาพของฉากต่อสู้อยู่ที่นั่น ไม่ซ้ำกัน)
ไฟล์นี้บอกว่าหน้าจออื่นที่ไม่ใช่ฉากต่อสู้ต้องใช้ภาพอะไร ขนาดเท่าไร ชื่อไฟล์อะไร ให้ผู้ใช้วาดไปพร้อมกับที่ Claude ทำโค้ด
ตัวเลขทั้งหมดเป็นข้อเสนอของ Claude ปรับได้ ระหว่างที่ยังไม่มีภาพ เกมวาดกรอบว่างไว้ตรงที่ภาพจะอยู่ ขนาดเท่าที่จะวาดจริง

---

## 1. กติกาทุกภาพ

- **pixel ขยาย 2 เท่า** แบบเดียวกับฉากต่อสู้ : ให้คิดเหมือนวาดบนจอ 640×360 (เกมแสดงที่ 1280×720) ทุกขนาดในไฟล์นี้บอกเป็น 2 แบบ
  - **แคนวาส** = ขนาดที่วาดจริงใน Aseprite หรือโปรแกรมวาด (export ขนาดนี้ ไม่ต้องขยายเอง)
  - **บนจอ** = แคนวาสคูณ 2 (ขนาดกรอบในเกม)
- สี : ขาว ดำ เทา แบบ dramatic ทั้งเกม ตัวละครแต่ละตัวมีสีเดี่ยวของตัวเอง 1 สี (ตา ไฮไลต์ผม อาวุธ จุดเด่น) ขอรหัส hex ของแต่ละตัวด้วย เพราะ UI ของตัวนั้นจะใช้สีเดียวกัน
- แสง : ไฟเวทีส่องจากด้านบนเป็นหลัก โค้ดจะเติมแสงที่ขยับได้ทับอีกชั้นตามอารมณ์ของแต่ละห้อง (ข้อ 3) ภาพจึงไม่ต้องสว่างมาก ปล่อยเงาให้ลึกได้
- ไฟล์ : PNG ขอบคมแบบ pixel ภาพที่เป็นห้องหรือฉากเต็มกรอบไม่ต้องโปร่งใส ภาพตัวละครพื้นหลังโปร่งใส
- ชื่อไฟล์ : ตัวพิมพ์เล็กทั้งหมด เว้นวรรคกับ ' เปลี่ยนเป็น `_` เช่น A STREET MUSICIAN เป็น `a_street_musician` THE KING'S BATON เป็น `the_king_s_baton`
- ภาพเคลื่อนไหวไม่บังคับ ทุกช่องใช้ภาพนิ่งภาพเดียวได้ ถ้าอยากให้ขยับ (หายใจ ไฟกะพริบ) ทำแบบเดียวกับฉากต่อสู้ คือ Aseprite (`<ชื่อ>.png` + `<ชื่อ>.json`) หรือแยกเฟรม `<ชื่อ>_idle_0.png` `_idle_1.png` ...
- ห้ามมีตัวหนังสือในภาพ (ชื่อ ป้าย ตัวเลข) เพราะเกมเขียนเองและจะแปลภาษาไทยทีหลัง

### ภาพที่มีอยู่แล้ว
- `Content/Art/Conductors/gallery_the_unhearing.png` (302×402) และ `face_the_unhearing.png` (224×224) ไม่ใช่ pixel art ผู้ใช้ตัดสินแล้ว (28 ต.ค.) ว่า **ใช้ภาพเดิมต่อไป** ไม่ต้องวาดใหม่
- chibi ของนักดนตรี 9 ตัว (`Content/Art/Musicians/<ชื่อ>_idle_0.png` 112×112) ยังใช้ในหน้า BandName Band CurtainCall Recruit จะถูกแทนด้วยภาพหน้าในข้อ 2.1 (ยังไม่ได้ตัดสินว่าเอาออกเลยหรือรอภาพหน้าเสร็จ)

### ภาพไปอยู่ที่ไหน
- ตอนนี้ภาพนิ่งของหน้าจอโหลดผ่าน `Core/ArtBank.cs` ต้องเพิ่มไฟล์ใน `Content.mgcb` ก่อน (วิธีใน `Content/Art/README.txt`) และเกมยืดภาพให้เต็มกรอบแบบเนียน
- **โค้ดที่จะทำเมื่อภาพแรกมาถึง** : ให้ภาพ pixel ของหน้าจออ่านตรงจากโฟลเดอร์ `Content/Art/Ui/` เหมือนฉากต่อสู้ (`Core/FrameArt.cs`) ไม่ต้องแก้ `Content.mgcb` วางไฟล์แล้ว Rebuild ได้เลย และวาดคูณ 2 แบบคม (PointClamp) ไม่ยืด ไม่เบลอ โฟลเดอร์ย่อยตามตารางข้างล่าง

## 4. สิ่งที่โค้ดวาดเอง (ไม่ต้องมีภาพ)

- การ์ด Motif ทั้งหน้าและหลัง (ตัวอักษรย่อในเพชร ตามกติกา ห้ามวาดสัญลักษณ์ดนตรี) การ์ดพลิกและเอียงแบบ Balatro ทำด้วยโค้ด
- ม่านเวที (`Core/Curtain.cs`) แผ่นเฉียงตอนเปลี่ยนหน้า วงแหวนกวาด หลุมของ TACET แสงและเงาทุกห้อง
- ปุ่ม กรอบ เส้นคั่น ตัวเลข

5. ยุค แผนที่ เสาภาพ รอระบบใหม่
