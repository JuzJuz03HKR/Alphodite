# แผนอาร์ตของหน้าจอ (UI Art Plan)

เริ่ม 29 ต.ค. 2026 ใช้คู่กับ `docs/SCREENS_LEVEL_UP.md` (ข้อ 6) และ `docs/BATTLE_ART_PLAN.md` (ภาพของฉากต่อสู้อยู่ที่นั่น ไม่ซ้ำกัน)
ไฟล์นี้บอกว่าหน้าจออื่นที่ไม่ใช่ฉากต่อสู้ต้องใช้ภาพอะไร ขนาดเท่าไร ชื่อไฟล์อะไร ให้ผู้ใช้วาดไปพร้อมกับที่ Claude ทำโค้ด
ตัวเลขทั้งหมดเป็นข้อเสนอของ Claude ปรับได้ ระหว่างที่ยังไม่มีภาพ เกมวาดกรอบว่างไว้ตรงที่ภาพจะอยู่ ขนาดเท่าที่จะวาดจริง

---

## 1. กติกาทุกภาพ

- **pixel วาดที่ขนาดจริงบนจอ ไม่ขยาย** (ผู้ใช้ตัดสิน 29 ต.ค. `USER_BRIEFS.md` 13.13) 1 พิกเซลของภาพ = 1 game pixel ของจอ 1280×720 แบบเดียวกับภาพวาทยากร `gallery_the_unhearing.png` ที่มีอยู่
  - ทุกขนาดในไฟล์นี้คือขนาดแคนวาสที่วาดจริง และเท่ากับขนาดกรอบในเกม export ขนาดนี้เลย
  - ตัวละครในฉากต่อสู้ยังขยาย 2 เท่าตาม `BATTLE_ART_PLAN.md` (ไฟล์นี้เป็นภาพของหน้าจออื่นเท่านั้น)
  - ตอนแก้ข้อนี้ (29 ต.ค.) ตัวเลขแคนวาสในตารางข้างล่างถูกเปลี่ยนจากแบบครึ่งหนึ่ง (ขยาย 2 เท่า) เป็นขนาดจริงทั้งหมดแล้ว
- สี : ขาว ดำ เทา แบบ dramatic ทั้งเกม ตัวละครแต่ละตัวมีสีเดี่ยวของตัวเอง 1 สี (ตา ไฮไลต์ผม อาวุธ จุดเด่น) ขอรหัส hex ของแต่ละตัวด้วย เพราะ UI ของตัวนั้นจะใช้สีเดียวกัน
- แสง : ไฟเวทีส่องจากด้านบนเป็นหลัก โค้ดจะเติมแสงที่ขยับได้ทับอีกชั้นตามอารมณ์ของแต่ละห้อง (ข้อ 3) ภาพจึงไม่ต้องสว่างมาก ปล่อยเงาให้ลึกได้
- ไฟล์ : PNG ขอบคมแบบ pixel ภาพที่เป็นห้องหรือฉากเต็มกรอบไม่ต้องโปร่งใส ภาพตัวละครพื้นหลังโปร่งใส
- ชื่อไฟล์ : ตัวพิมพ์เล็กทั้งหมด เว้นวรรคกับ ' เปลี่ยนเป็น `_` เช่น A STREET MUSICIAN เป็น `a_street_musician` THE KING'S BATON เป็น `the_king_s_baton`
- ภาพเคลื่อนไหวไม่บังคับ ทุกช่องใช้ภาพนิ่งภาพเดียวได้ ถ้าอยากให้ขยับ (หายใจ ไฟกะพริบ) ทำแบบเดียวกับฉากต่อสู้ คือ Aseprite (`<ชื่อ>.png` + `<ชื่อ>.json`) หรือแยกเฟรม `<ชื่อ>_idle_0.png` `_idle_1.png` ...
- ห้ามมีตัวหนังสือในภาพ (ชื่อ ป้าย ตัวเลข) เพราะเกมเขียนเองและจะแปลภาษาไทยทีหลัง

### ภาพที่มีอยู่แล้ว
- `Content/Art/Conductors/gallery_the_unhearing.png` (302×402) และ `face_the_unhearing.png` (224×224) **เป็น pixel art วาดที่ขนาดจริง** (1 พิกเซลของภาพ = 1 game pixel ละเอียดกว่าตัวในฉากต่อสู้ที่ขยาย 2 เท่า) ผู้ใช้ยืนยัน 29 ต.ค. ว่า "อาร์ตเป็นแบบ pixel อยู่แล้ว" (แชทก่อนเข้าใจผิดว่าไม่ใช่ pixel) ใช้ภาพเดิมต่อไป
- chibi ของนักดนตรีชุดเดิม 9 ตัว (`Content/Art/Musicians/<ชื่อ>_idle_0.png` 112×112) เป็นคนละคนกับนักดนตรีในตำนาน 5 คน (29 ต.ค.) ชื่อไฟล์ผูกกับชื่อตัวละคร จึงไม่โชว์กับ 5 คนนี้แล้ว หน้าที่เคยใช้ chibi (Rest Event) โชว์กรอบว่างแทน รอภาพหน้าในข้อ 2.1 ไฟล์เดิมยังอยู่ ลบได้เมื่อทีมไม่ต้องการ

### ภาพไปอยู่ที่ไหน
- ตอนนี้ภาพนิ่งของหน้าจอโหลดผ่าน `Core/ArtBank.cs` ต้องเพิ่มไฟล์ใน `Content.mgcb` ก่อน (วิธีใน `Content/Art/README.txt`) และเกมยืดภาพให้เต็มกรอบแบบเนียน
- **โค้ดที่จะทำเมื่อภาพแรกมาถึง** : ให้ภาพ pixel ของหน้าจออ่านตรงจากโฟลเดอร์ `Content/Art/Ui/` เหมือนฉากต่อสู้ (`Core/FrameArt.cs`) ไม่ต้องแก้ `Content.mgcb` วางไฟล์แล้ว Rebuild ได้เลย วาดขนาดจริงไม่ยืด โฟลเดอร์ย่อยตามตารางข้างล่าง
  - เต็มจอ 1920×1080 ภาพขนาดจริงถูกขยาย 1.5 เท่า (ไม่ลงตัว) ต้องลองกับภาพจริงว่าจะวาดแบบคม (PointClamp พิกเซลกว้างไม่เท่ากันนิดหน่อย) หรือแบบเนียน (LinearClamp ตอนนี้) แล้วให้ผู้ใช้เลือก ที่ 2560×1440 และ 4K เป็น 2 และ 3 เท่าพอดี คมทุกพิกเซล
