# งานคู่ขนาน 2 แชท : หน้าบ้านกับหลังบ้าน

แผน 2 พ.ย. แชท FINALE1 (ผู้ใช้ถามวิธีแยกงาน `USER_BRIEFS.md` 13.90 แล้วเลือกแบบหน้าบ้านหลังบ้าน 13.91 : "คนนึงทำงานอาร์ต และการแสดงผล อีกคนทำระบบ แต่คือทำคนละส่วนคนละที่กันไปเลย")
สถานะ : **เก็บไว้ ยังไม่ใช้** ผู้ใช้เลือกทำทีละส่วนในแชทเดียว (2 พ.ย. `USER_BRIEFS.md` 13.92) ข้อ 0 ไม่ได้ทำ ถ้าวันหลังจะแยกสองแชทให้เริ่มจากข้อ 0 / แผนแรกที่แบ่งฝั่งวงกับฝั่ง TACET (ทั้งสองแชททำอาร์ต) ยกเลิกแล้ว

## หลักการ

โค้ดเกมแยกภาพออกจากกติกาอยู่แล้ว : `TurnBattle` ไม่มีโค้ดวาด กติกาเขียนผลลงเป็นเหตุการณ์ (`TurnEvent`) หน้าจออ่านเหตุการณ์แล้ววาด
จึงแบ่งตามโฟลเดอร์ได้ แต่ละแชทเป็นเจ้าของโฟลเดอร์ของตัวเอง ไม่แก้ของอีกฝ่าย สองแชทแก้คนละไฟล์ git รวมงานเองโดยไม่ชนกัน
จุดที่สองฝ่ายต่อกันมีจุดเดียว : เหตุการณ์ในไฟต์ ข้อ 0 ทำช่องให้ระบบเสียงของหลังบ้านฟังเหตุการณ์เดียวกับที่หน้าจอใช้ โดยไม่ต้องแตะหน้าจอ

## หน้าบ้าน (ART) : อาร์ตกับการแสดงผล

แชท FINALE1 ทำต่อ เพราะรู้ดีไซน์ครบแล้ว
งานตามลำดับ จบแต่ละข้อส่งภาพให้ผู้ใช้ดู
1. ตัวละครฉากต่อสู้รอบ 6 (`BETA1_DIRECTION.md` 32 ถึง 32.13 สเก็ตช์ `docs/art_refs/concept_v6.html`) : นักดนตรี 5 คน แล้ว TACET 4 แบบ แล้วบอส 6 ตัว แล้วเวที (คงฉากหลอกตา 3D เพิ่มแสงบนพื้นกับเงาสะท้อน)
2. ท่าโจมตีของทุกตัว (13.89)
3. VFX ทั้งหมด ก้อน D (`HANDOFF.md` 00.3 รอภาพจากผู้ใช้) รวม VFX วาทยากร สายฟ้า Beethoven ฟ้าก่อนแล้วค่อยแดง
4. GUI รอบสุดท้าย ก้อน C (ยกเว้น C5 ที่เป็นของหลังบ้าน) และแถบเลื่อนระดับเสียงบนหน้าตั้งค่าเมื่อหลังบ้านทำค่าไว้แล้ว

ไฟล์ของหน้าบ้าน (หลังบ้านห้ามแตะ)

## หลังบ้าน (SYSTEM) : ระบบ

เปิดแชทใหม่ด้วยพรอมต์ท้ายไฟล์
งานตามลำดับ จบแต่ละข้อรายงานผู้ใช้ (ส่วนที่ต้องเลือกถามก่อนเขียนโค้ด)
1. **ระบบเสียงทั้งเกม** (ก้อน E1 กับเตรียม E2) เพราะผู้ใช้จะส่งเสียงทั้งหมดมารวดเดียว (13.57)
   - อ่านไฟล์เสียงตรงจากโฟลเดอร์ วางไฟล์แล้ว Rebuild ได้เลย ไม่ต้องแก้ `Content.mgcb` (แบบเดียวกับภาพใน `Content/Art/`)
   - จุดเล่นเสียงในไฟต์ทั้งหมดจาก `ASSET_LIST.md` S3 กับเสียงที่โค้ดเล่นอยู่แล้ว S2 ผ่าน `Audio/SoundCues.cs` ที่ฟังเหตุการณ์ในไฟต์
   - เสียงตี = เสียงเครื่องดนตรีผสมเสียงอาวุธ (13.39) สุ่มระดับเสียงนิดหน่อยไม่ให้ซ้ำหู จำกัดจำนวนเสียงที่ดังพร้อมกัน
   - เพลงเปลี่ยนตามหน้า ตามบอส และตอน THE TURN แบบค่อยๆ เฟด (หน้าจอเรียก `SoundBank.PlayMusic` อยู่แล้ว แก้ข้างในได้โดยไม่แตะหน้าจอ)
   - ระดับเสียงเพลงกับเอฟเฟกต์แยกกันใน `Core/Settings.cs` (แถบเลื่อนบนหน้าตั้งค่าเป็นงานของหน้าบ้าน)
   - ไม่มีไฟล์ก็เงียบไม่พัง ห้ามใส่เสียงชั่วคราว (CLAUDE.md ข้อ 3) / เทสใหม่ `--shots soundcheck` / อัปเดตชื่อไฟล์เสียงกับที่วางใน `ASSET_LIST.md` ให้ผู้ใช้ตั้งชื่อตาม
2. **ระบบโหลดภาพ** (`ASSET_LIST.md` ข้อ 9.10 9.12) : วาทยากรอ่านภาพตรงจากโฟลเดอร์ / F3 นับภาพในโฟลเดอร์ `Battle` กับ `Ui` ด้วย
3. **build สำหรับขาย** (ก้อน H) : เอาไฟล์ที่ไม่ใช้ออกจาก `Content.mgcb` (9.14) / `DebugShots` อยู่ใน `#if DEBUG` (build แบบ Debug ยังแคปภาพได้) / แพ็กเกจที่ไม่ใช้ / เซฟกันพัง (เขียนไฟล์ใหม่ก่อนแล้วค่อยแทนของเดิม เก็บสำรองหนึ่งชุด) / บันทึกสาเหตุตอนเกมพัง / ขั้นตอนทำไฟล์เกม Windows / ❓ TEST ROOM ในตัวขาย ถามผู้ใช้ก่อน
4. ❓ **คุยกับผู้ใช้ก่อนเขียนโค้ด** : COMBO / ความโหดแบบทวีคูณกับช่วงเบิร์ส / ระบบเงินที่เฟ้อกับดอกเบี้ย (ผู้ใช้บอกให้ทำตอน balance รอบสุดท้าย เตรียมข้อเสนอไว้ก่อนได้)

## กติการะหว่างทำ

- **เหตุการณ์ในไฟต์** : หลังบ้านเพิ่มชนิดใหม่ต่อท้ายได้ ห้ามเปลี่ยนความหมายของที่มีอยู่ เพราะหน้าบ้านวาดตามนั้น / หน้าบ้านห้ามแก้กติกา ถ้าภาพต้องรู้อะไรเพิ่มเขียนคำถามอ่านอย่างเดียวใน `TurnBattle.Look.cs`
- **ทั้งสองแชททำบน `Beta1`** ก่อน push ทุกครั้งใช้ `/sync` (pull แบบ merge) ถ้า pull แล้วมีโค้ดของอีกฝ่ายเข้ามา build กับเทสอีกรอบก่อน push
- **push เฉพาะงานที่ build 0/0 turncheck savecheck ผ่าน** ผู้ใช้ Rebuild ได้ทุกเมื่อ ต้องไม่เจองานพังของอีกฝ่าย / หน้าบ้านไม่แตะกติกา turncheck กับ savecheck จึงต้องเท่าเดิม / หลังบ้านเปลี่ยนเลขเทสได้เมื่อเพิ่มเทส บอกในรายงาน
- **ต้องใช้ไฟล์ของอีกฝ่าย** : ห้ามแก้เอง เขียนคำขอในแถวของตัวเองในตาราง "แชทที่กำลังทำงาน" ของ `RESUME_PROMPT.md` แล้วบอกผู้ใช้ ผู้ใช้ส่งต่อให้อีกแชท
- **เอกสาร** : หน้าบ้านเขียน `BETA1_DIRECTION.md` 33 กับ `USER_BRIEFS.md` 13.F (เลขย่อย 13.F1 13.F2 ...) / หลังบ้านเขียน 34 กับ 13.S (13.S1 ...) / `RESUME_PROMPT.md` แก้แค่แถวกับบล็อกสถานะของตัวเอง / `CLAUDE.md` กับ `HANDOFF.md` แก้แค่บรรทัดของฝ่ายตัวเองที่ข้อ 0 เตรียมไว้
- **ผู้ใช้คุยกับแต่ละแชทแยกกัน** เรื่องภาพคุยกับหน้าบ้าน เรื่องระบบกับเสียงคุยกับหลังบ้าน
- **token** : สองแชทใช้รวมกันพอๆ กับทำทีละอย่าง บวกค่าเปิดแชทใหม่อีกหนึ่ง แต่ได้งานสองสายพร้อมกัน
