## กติการะหว่างทำ

- ทำบน `Beta1` ทั้งคู่ ก่อน push ทุกครั้งใช้ `/sync` (pull แบบ merge) ไฟล์ไม่ทับกัน git จึงรวมเอง ถ้า pull แล้วมีโค้ดของอีกทางเข้ามา build กับเทสอีกรอบก่อน push
- push เฉพาะงานที่ build 0/0 turncheck 204/204 savecheck 44/44 ผ่าน ผู้ใช้ Rebuild ได้ทุกเมื่อ ต้องไม่เจองานพังของอีกทาง
- เอกสาร : ทาง A เขียน `BETA1_DIRECTION.md` 33 กับ `USER_BRIEFS.md` 13.A / ทาง B เขียน 34 กับ 13.B (เลขย่อย 13.A1 13.A2 ... กับ 13.B1 ...) / `RESUME_PROMPT.md` แก้แค่แถวกับบล็อกของตัวเอง
- ภาพความคืบหน้าที่จะเก็บใน `docs/art_refs/` ใช้ชื่อขึ้นต้น `progress_band_` หรือ `progress_tacet_`
- ผู้ใช้คุยกับแต่ละแชทแยกกัน ความเห็นที่เป็นของอีกทาง ผู้ใช้ส่งต่อเอง
- token : สองแชทใช้รวมกันพอๆ กับทำทีละทาง บวกค่าเปิดแชทใหม่อีกหนึ่งแชท แต่เสร็จเร็วขึ้นราวครึ่งหนึ่ง
