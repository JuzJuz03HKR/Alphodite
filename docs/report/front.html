คำนำ

รายงานฉบับนี้จัดทำขึ้นเพื่ออธิบายโครงสร้างข้อมูลที่ทีม Alphodite นำไปใช้ และวางแผนจะนำไปใช้ในการพัฒนาเกม TACET 4'33 ซึ่งเป็นเกมแนว roguelike แบบผลัดกันเล่น ผู้เล่นรับบทวาทยากรที่ใช้เมาส์ตวัดแทนไม้บาตอง เกมพัฒนาด้วยภาษา C# บน MonoGame

เนื้อหาแบ่งตามหัวข้อที่เรียนในรายวิชา ได้แก่ Arrays and Sorting, Variants of Lists, Key-Value Pair Data Structures, Variants of Trees และ Exploring Graphs แต่ละหัวข้อยกตัวอย่างเด่นจากโค้ดจริงของเกม อธิบายว่าเลือกโครงสร้างนั้นเพราะอะไร ใช้เวลาทำงานเท่าไร และมีข้อควรระวังอะไร พร้อม UML class diagram ไดอะแกรม และโค้ดประกอบ

ส่วนที่ยังไม่ได้อยู่ในเกม คือ heap สำหรับลำดับเทิร์น decision tree สำหรับศัตรู และแผนที่แบบกราฟ ระบุไว้ชัดเจนว่าเป็นแผน โค้ดร่างของแผนเหล่านี้ได้นำไปคอมไพล์และทดสอบในโปรแกรมทดสอบแยกแล้ว และบอกผลทดสอบไว้ในเนื้อหา

คณะผู้จัดทำหวังว่ารายงานฉบับนี้จะช่วยให้เห็นว่าการเลือกโครงสร้างข้อมูลมีผลต่อความเร็ว ความถูกต้อง และการดูแลโค้ดของเกมอย่างไร หากมีข้อผิดพลาดประการใด คณะผู้จัดทำขออภัยมา ณ ที่นี้
