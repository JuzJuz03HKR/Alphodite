# /note : จดทันที

ข้อความที่ให้จด (อาจว่าง): $ARGUMENTS

ใช้เมื่อผู้ใช้เพิ่งสั่งหรืออธิบายอะไรสำคัญ แล้วไม่อยากให้หายถ้า context เต็มก่อนพิมพ์ /update
การพิมพ์ /note ถือว่าผู้ใช้อนุญาตให้ commit และ push ไฟล์เอกสารที่จดแล้ว

## ขั้นตอน

1. **เลือกสิ่งที่จะจด** : ถ้ามี $ARGUMENTS จดข้อความนั้น ถ้าไม่มี จดข้อความของผู้ใช้ในแชทนี้ที่ยังไม่อยู่ใน `docs/USER_BRIEFS.md`
2. **จดคำต่อคำ** ต่อท้ายหัวข้อล่าสุดของ `docs/USER_BRIEFS.md` (ตอนนี้คือข้อ 12 Alpha 7)
   - ขึ้นต้นด้วยวันที่และหัวเรื่องสั้นๆ แล้ววางข้อความในกล่อง ```` ```text ````
   - ตามด้วยบรรทัด `→` สรุปว่าผู้ใช้ตัดสินใจอะไร หรือข้อความนี้มีผลกับอะไร
3. ถ้าเป็นการตัดสินใจที่เปลี่ยนกติกาหรือการออกแบบ ให้ใส่หนึ่งบรรทัดใน `CLAUDE.md` หัวข้อ 0 หรือ `docs/ALPHA7_DESIGN.md` ด้วย ถ้าไม่แน่ใจว่าควรอยู่ที่ไหนให้ถาม
4. คง BOM เดิมของไฟล์ และบรรทัดเป็น LF
5. commit เฉพาะไฟล์เอกสารที่จด แล้ว `git push -u origin <branch ที่ทำงานอยู่>` (ถ้า GitHub มี commit ใหม่ให้ `git pull --no-rebase` ก่อน ห้าม force)
6. ตอบผู้ใช้บรรทัดเดียวว่าจดอะไรไว้ที่ไหน
