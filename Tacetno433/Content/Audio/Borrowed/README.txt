BORROWED SOUNDS (closed playtest only, block E 2 Nov 2026)
==========================================================

Put the borrowed sounds and music here before building the playtest build : the files of
TACET_borrowed_audio.zip, or any file named like the ones in ../Sfx and ../Music.
A file here wins over the free one with the same name.

Today these are the team's own picks (TEAM FREE) : free sounds the team found on free sound
websites and checked free to use (the user, 2 Nov). The site of each file was not written down,
so they stay out of the public repository : git ignores every file in this folder except this
README (.gitignore). They are kept in the team's Google Drive folder soundgame. Anything borrowed
from another game for the closed playtest would go here too (BORROWED, none yet).
Every one of them is credited in docs/CREDITS.md and on the CREDITS page of the game.
